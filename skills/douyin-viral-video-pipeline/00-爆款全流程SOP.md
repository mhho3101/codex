## 阶段 ① 选题与情报

**目标**：不做"我觉得这个能火"，只做"数据说这个在火"。

**用哪些包**

| 技能包 | 位置 | 用途 |
|---|---|---|
| 抖音对标账号采集 | `01-选题与情报\抖音对标账号采集` | 采集对标账号的作品列表与数据 |
| 爆款选题公式 | `01-选题与情报\爆款选题公式` | 用公式把热点转成选题 |
| TikHub多平台数据API | `01-选题与情报\TikHub多平台数据API` | 多平台数据接口（需申请 Key） |
| FactReach全网搜索 | `01-选题与情报\FactReach全网搜索` | 全网资料检索，支撑内容论证 |

**操作步骤**

1. 锁定 3–5 个同赛道对标账号（粉丝量在你 3–10 倍之间的最容易抄结构）。
2. 采最近 30 条作品的数据，按点赞／评论排序。
3. 找出**反复出现的选题母题**（同一个母题至少出现 3 次 = 赛道验证过）。
4. 用选题公式产出 10–20 个候选，排序后留 3 个。

**提示词模板**

```text
读取 $ROOT\01-选题与情报\抖音对标账号采集\SKILL.md，
按它的方法采集以下账号最近 30 条作品的数据：
[账号1 / 账号2 / 账号3]
赛道是：[你的赛道，例如 家庭收纳 / 母婴 / 职场干货]

输出：作品标题、点赞、评论、收藏、时长、发布日期，按点赞降序。
然后总结：这些账号反复使用的 5 个选题母题是什么？各自出现几次？
```

```text
读取 $ROOT\01-选题与情报\爆款选题公式\SKILL.md，
基于上面找出的 5 个母题，为我的账号生成 20 个具体选题。
我的账号定位：[一句话说清你是谁、给谁看、解决什么]
我的内容形式：[真人口播 / 剧情 / 图文轮播 / 教程 / 带货]

要求：每个选题给出「标题 + 目标人群 + 核心利益点 + 预估爆点」，
并打分排序，最后只留前 3 个。
```

> ⚠️ 采集类操作依赖浏览器登录态与第三方接口。遵守平台规则与《个人信息保护法》，不要批量爬取、不要买卖数据。

## 阶段 ② 爆款拆解（本套件最高优先级）

**目标**：把一条爆款拆成**结构**——你能借的是结构，不是画面。

> **做爆款的前提是拆爆款。** 如果时间只够用一个阶段，就用这个。

**用哪些包**

| 技能包 | 位置 | 用途 |
|---|---|---|
| 爆款视频拆解包 ★首选 | `02-爆款拆解\爆款视频拆解包` | 下载 + 逐字稿 + 关键帧 + 评论洞察 |
| 爆款视频逐镜拆解 | `02-爆款拆解\爆款视频逐镜拆解` | 镜头级拉片，直接输出 AI 生成 brief |
| 抖音TopN采集改写 | `02-爆款拆解\抖音TopN采集改写` | 批量：Top N 采集 → 转写 → 改写 |
| Hook实验室 | `02-爆款拆解\Hook实验室` | 批量测试钩子 |
| 抽帧OCR字幕提取 | `02-爆款拆解\抽帧OCR字幕提取` | 画面内硬字幕提取 |

**拆解包的标准产出**（拆完你会得到这 4 个文件）

```
拆解结果/
├── source.mp4                 原片
├── keyframes/                 关键帧截图
├── speaker_transcript.md      带说话人区分的逐字稿
└── story_analysis.md          ★ 拆解报告：钩子 / 节拍 / 反转 / 节奏 / 评论区共鸣
```

**拆解报告要看的 6 件事**

1. **前 3 秒**：说了什么？给了什么画面？为什么能让人不划走？
2. **前 5 秒**：有没有二次钩子？
3. **节拍**：一共几个情节点？每个多长？（通常 30 秒里有 4–6 个）
4. **反转 / 兑现**：把什么悬念留到了最后？什么时候给的？
5. **镜头节奏**：平均每个镜头几秒？有没有一次性加速／静音处理？
6. **评论区共鸣**：高赞评论在说什么情绪？观众为什么愿意评论？

**提示词模板**

```text
读取 $ROOT\02-爆款拆解\爆款视频拆解包\SKILL.md，
按它的完整流程拆解这条视频：[抖音分享链接 或 本地视频路径]
输出目录：[你指定的目录]

要求：
1. 严格按 SKILL.md 的 Output Contract 产出 4 个可见文件
2. story_analysis.md 必须是具体的创作者研究报告，不要留「待补充」之类的占位
3. 评论区只采约 30 条，保守采集，不深度翻页
4. 最后单独给我一段「这条视频我哪里能借、哪里不能抄」的判断
```

```text
读取 $ROOT\02-爆款拆解\爆款视频逐镜拆解\SKILL.md，
对上面拆解出的 source.mp4 做镜头级拉片，输出：
- 每个镜头的起止时间、景别、运镜、画面内容、字幕、音效
- 输出的「AI 生成 brief」要能直接投喂给视频生成模型
```

> 批量做的时候用 `抖音TopN采集改写`：一次把 20 条爆款采下来 → 转写 → 改写成本赛道脚本，比手工快 10 倍。

| 薛辉变现思维 | `03-脚本与钩子\薛辉变现思维` | 内容变现路径设计 |
| 千川获客脚本 | `03-脚本与钩子\千川获客脚本` | 投流素材脚本 |
| 短视频获客编导 | `03-脚本与钩子\短视频获客编导` | 获客型编导思维（⛔ 禁商用） |
| 爆款短剧编剧引擎 | `03-脚本与钩子\爆款短剧编剧引擎` | 剧情 / 短剧类脚本 |

**钩子铁律**

- 口播**不超过 3 秒**，画面字数 **6–18 个汉字**
- 只表达**一个**刺激点
- 类型要有差异：反常识 / 痛点 / 数字承诺 / 悬念 / 冲突 / 情绪 / 故事 / 身份代入 / 结果前置 / 错误警告
- 不用「震惊」「看完惊呆」这类陈旧标题党
- **不许编造**数据、案例、收益、疗效、稀缺性

**提示词模板**

```text
15/30/60 秒脚本、镜头级分镜、口播节奏、BGM/SFX 建议、
标题、封面文案、简介、A/B 测试方案、数据复盘规则。
```

