# 需求规范（开源精简版）

## 一、分工边界

| 职责 | 由谁负责 |
|------|---------|
| 分析字幕、规划片段（SEGMENTS） | AI（参照 style_guide.md） |
| 执行切割、导出视频 | cut_clips.py（读取 JSON 配置） |
| 旁白花字文案 | AI（写入 JSON narrations 字段） |
| 比例转换(9:16)、字幕、背景音乐、后期 | 用户（剪映） |

输出原片规格的碎片、默认拼接成片、对应关系 txt 和实际结果清单。可以重编码，但不改变画面尺寸，不自动添加旁白、字幕或配乐。

## 二、配置格式（JSON）

配置文件模板见 `assets/movie_config_template.json`，结构：

```json
{
  "movie_name": "电影名",
  "src": "原片路径",
  "out_dir": "输出目录",
  "ffmpeg": "ffmpeg 路径或命令名",
  "ffprobe": "ffprobe 路径或命令名",
  "head_end": 0,
  "tail_start": 7200,
  "min_duration": 50,
  "max_duration": 75,
  "segments": [
    {
      "num": 1,
      "title": "网感副标题",
      "clips": [[起始秒, 结束秒], ...],
      "narrations": [{"text": "旁白文案", "clip": 片段编号, "after_sec": 段内秒}, ...]
    }
  ]
}
```

## 三、输出格式（默认拼接并保留碎片）

每条视频一个目录，目录下放独立片段文件：

```
输出目录/
├── 电影名（1）副标题/
│   ├── 电影名（1）副标题-1.mp4
│   ├── 电影名（1）副标题-2.mp4
│   ├── 电影名（1）副标题-3.mp4
│   ├── 电影名（1）副标题.mp4      # 拼接成片
│   └── 电影名（1）副标题.txt      # 片段构成 + 旁白 + 对白参考
├── 电影名（2）副标题/
│   └── ...
└── 电影名_segments_manifest.json   # 剪辑清单（供后续分析）
```

## 四、切割规格

- 无损流复制（`-c copy`），画质 100% 等于原片
- 时长偏差：流复制可能偏离计划起止点；实际成片仍需符合 50–75 秒，超出则调整或用 `--reencode` 重做
- 默认拼接成片并保留碎片；仅需碎片时用 `--no-merge`，用户可在剪映继续排列

上方结构中的 7200 只是示例，必须换成确认后的片尾起点；可直接修改的合法 JSON 示例见配置模板。
