# 基础剪辑风格规则（开源精简版）

> **用途**：AI 为电影生成 SEGMENTS 时参照此文件。
> 这是通用基础规则。完整版提供基于 17 条真实样片提炼的精细版风格指南（快剪串烧参数、旁白落点规则、样板片段配方）与自动学习闭环。

## 一、结构规则

| 规则 | 数值 |
|---|---|
| 数量 | 每部电影 8-15 条 |
| 总时长 | 每条 50-75 秒（计划和实际成片都检查） |
| 结构 | 一条只讲一个事，可跨时间挑片段拼接 |
| 碎片数 | **每条 3-7 个碎片**（快剪串烧风，禁止整条单段；暂定 2026-08-13） |

## 二、选段规则

### 保留

- 推进剧情的对白
- 关键冲突 / 反转
- 打斗、变身、高能动作（保留核心中间段）
- 一句关键台词做 callback（单独切 1-3s 碎片）

### 删除

- 走路 / 开车 / 风景过场
- 发呆 / 沉默 / 无意义停顿
- 感叹 / 闲聊 / 不推进剧情的对话（如"好美呀""太美了"）

## 三、旁白规则

| 规则 | 数值 |
|---|---|
| 密度 | 每条 3-4 条旁白 |
| 内容 | 交代因果/人物背景/动机/即将发生的反转；**不复述对白**、不描述画面已在发生的事 |
| 时长 | 单条 2-10 秒 |

## 四、命名规则

- 副标题有网感（如"以为捡到宝贝结果是食人蚁"）
- 每条第一帧有看点（可作封面），避免黑屏/logo/路人甲背影

## 五、生成后自查清单

- [ ] 每条只讲一个主题
- [ ] 每条 3-7 个碎片（快剪串烧风），**无整条单段**（除极端情况）
- [ ] 碎片来自不同时间段，非同一场景连续切片
- [ ] **条间时间戳互斥**（不同条之间无重叠/重复引用同一场景）
- [ ] 每条有 hook（抓眼开头）+ 主体 + callback
- [ ] **每条时长按预算分配**（先定总预算再分碎片，非先选后算）
- [ ] 总时长 50-75s
- [ ] 删除了所有过场（走路/风景/发呆/感叹）
- [ ] 旁白 3-4 条，交代因果/背景/反转，不复述对白
- [ ] 副标题有网感
- [ ] 副标题无 Windows 非法字符（/ \ : * ? " < > |）
- [ ] 第一帧有看点
- [ ] 无片段落在片头片尾区间（每条 clips 结束时间 < 片尾起点）
