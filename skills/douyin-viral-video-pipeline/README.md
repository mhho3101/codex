## 三、怎么用（3 步）

### 第 1 步：让 Agent 能读到技能包

技能包已在本机，**用绝对路径引用即可，无需安装**：

```text
读取 E:\codex\2026-09-28\ban\outputs\技能包精选\03-脚本与钩子\爆款3秒钩子脚本\viral-hook-script-skill\SKILL.md，
按它的方法帮我写一条"XXX"的抖音脚本。
```

不确定该读哪个文件时，直接说：

```text
读取 E:\codex\2026-09-28\ban\outputs\技能包精选\技能包入口索引.csv，
找到"爆款视频拆解包"这一行，按它给的入口文件路径读取并执行。
```

想让 Codex 自动识别，做一次目录链接（管理员 PowerShell）：

```powershell
New-Item -ItemType Junction `
  -Path "$env:USERPROFILE\.codex\skills\爆款视频拆解包" `
  -Target "E:\codex\2026-09-28\ban\outputs\技能包精选\02-爆款拆解\爆款视频拆解包"
```

也可以把整件事交给 Agent：

```text
请把 E:\codex\2026-09-28\ban\outputs\技能包精选 下我指定的技能包，
用目录名作为链接名，链接到 C:\Users\Administrator\.codex\skills。
先列出你打算链接哪些，等我确认后再执行。
```

### 第 2 步：补齐系统依赖

```powershell
winget install Gyan.FFmpeg          # ffmpeg / ffprobe —— 几乎所有视频包都要
winget install yt-dlp.yt-dlp        # 下载视频
winget install Python.Python.3.12   # Python 类技能包
winget install OpenJS.NodeJS.LTS    # Remotion / HyperFrames / 剪映类
```

**本机实测**：Git ✅　Node ✅　Python ✅　｜　**ffmpeg ❌ · yt-dlp ❌ —— 这两个必装**，否则多数包直接报错。

### 第 3 步：按 SOP 跑一遍

打开 **`00-爆款全流程SOP.md`**，8 个阶段的提示词模板逐条复制给 Agent 即可。
想快点见效，先看 **`00-快速上手-15分钟出片.md`**。
