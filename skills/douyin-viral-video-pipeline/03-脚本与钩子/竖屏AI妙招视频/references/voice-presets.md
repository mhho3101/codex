# 配音音色详解(Seedance 原生 AI 配音)

> Stage 7 生成视频时按需查阅。SKILL.md 正文只放速查表,细节都在这里。

## 原理:没有"音色 ID",音色靠 prompt 召唤

Seedance 1.5 pro 不是传统 TTS,而是端到端音视频联合生成模型。音色完全由 prompt
自然语言描述"召唤"——**描述越骨架化(如 `音频:AI 女声口播'<台词>'`),模型越退到
默认"标准播音腔",听感僵硬;描述越具体(音色质感 + 情绪 + 语速 + 场景化定位 4 个维度),
人声越自然贴合内容。**

`api_client.py` 基于 `--voice-preset` 自动拼出富信息音频指令,例如默认 preset 拼出来是:

```
音频:AI 年轻、清亮、亲切、带一点轻松笑意的声线女声口播,
情绪轻松友好,像跟朋友分享小窍门,语速中速自然,不刻意拖长,
台词:'把切好的香蕉皮放进玻璃罐'
```

你只需要在 motion prompt 里写画面运动,**不要写"配音""旁白"这些词**,音频指令由脚本拼接。

## 内置 preset(6 个)

| Preset | 标签 | 性别 | 适配场景 |
|--------|------|------|---------|
| `friendly-girl`(默认) | 亲切邻家女孩 | 女 | 生活妙招通用,大多数题材的安全选择 |
| `warm-mama` | 温暖妈妈 | 女 | 传统手艺 / 古法配方 / 长辈代代相传感 |
| `chirpy-host` | 活泼达人 | 女 | 年轻向 / 反差感强 / 种草号 |
| `wisdom-aunt` | 知性阿姨 | 女 | 科普向 / 原理讲解 / 知识带货 |
| `folksy-uncle` | 接地气大叔 | 男 | 乡土 / 户外 / 硬核实操类 |
| `calm-narrator` | 沉稳旁白 | 男 | 测评 / 对比讲解 / 纪录片感 |

preset 自带性别;显式传 `--voice-gender` 时以显式值为准(如 `warm-mama` + `--voice-gender male`
会变成"温暖成熟稍低沉的中年声线男声")。

## 选 preset 的判断规则

- 用户没说音色偏好 → 用**题材包推荐的默认 preset**(没有题材包就 `friendly-girl`),**不主动问**
- 用户说"温暖一点 / 传统感" → `warm-mama`
- 用户说"活泼一点 / 年轻向" → `chirpy-host`
- 用户说"科普感 / 专业一点" → `wisdom-aunt`
- 用户说"男声 / 大叔感" → `folksy-uncle` 或 `calm-narrator`
- 用户说"方言"(四川话/粤语/东北话等)→ **不要找 preset**,用
  `--voice-style "亲切的中年女声,四川话"` 这类自由描述(Seedance 官方支持四川/粤语/陕西/东北话)
- 用户说"我想要 XX 感觉的声音" → 把原话直接传 `--voice-style "<用户原话>"`
- 用户给了完整音频 prompt → `--voice-prompt-override`

## 细粒度覆盖参数(优先级:细粒度参数 > preset 对应字段)

- `--voice-style "慵懒磁性的低沉女声"` — 覆盖音色质感(**方言走这个**)
- `--voice-emotion "神秘悬念"` — 覆盖情绪基调
- `--voice-pace "缓慢一字一顿"` — 覆盖语速
- `--voice-gender male` — 覆盖性别
- `--voice-prompt-override "音频:AI ...完整指令...,台词:'...'"` — [逃生舱] 整段自定义
- `--generate-audio false` — 关掉配音(只要画面,后期剪映自己配)

## 台词写法要点

- 每镜 8-15 个汉字,5 秒画面读起来最自然;>15 字模型可能读不完
- 写成能直接读出来的口语,不要写视觉描述或导演笔记
- 模型会根据画面节奏自动微调语速,音画同步是自动的

## 常见问题

- **配音僵硬像播音腔**:几乎都是音频指令太骨架。换 preset 或用 `--voice-style` 加具体描述
- **读错字**:Seedance 偶发,重新生成那一镜通常解决;高频出错的字眼换个写法
- **没有人声只有环境音**:`--voiceover-text` 传了空台词,检查 jobs.json 里该镜的 `voiceover_text`
- **想换语言**:中文(普通话+方言)、英文、日韩西语、印尼语都支持,台词写对应语言即可
