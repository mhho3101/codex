# 双锚定方案 · 范例

> 这是 SKILL.md Stage 2 输出格式的样例,案例取自**三农园艺题材**;其他题材(美食/清洁/宠物等)
> 结构完全相同,只是要素内容不同。**仅作格式参考**,实际方案要根据用户选定的选题重新设计。
>
> 默认结构:**3 镜 × 5 秒 = 15 秒,9:16 竖屏**(镜头数/时长可按 SKILL.md 默认值规则调整)。

---

## 范例 A · 选题 "草木灰拌土防根腐"

```
【双锚定方案 · 3 镜 × 5 秒 = 15 秒】

═══ 视觉锚定(空间维度,3 个镜头共享)═══

📌 固定要素

1. 场景背景:户外阳台木质露台,远处虚化的绿色阔叶植物丛
2. 主体容器:一个 15cm 直径的红陶素烧花盆,内有 80% 满的湿润棕色泥土,放在浅色木板桌面上
3. 拍摄视角:45 度俯视近景特写,9:16 竖屏画幅,主体居中占画面 65%
4. 光线:正午阳光柔和散射,无强烈方向光,无明显阴影
5. 色调氛围:温暖土系色调,黄棕色为主,叶片绿色为辅

═══ 叙事锚定(时间维度,3 镜状态承接)═══

📖 故事弧线:撒草木灰 → 拌入泥土 → 移栽幼苗

镜头 1 (5s):起点 - 撒草木灰
- 开始状态:花盆里只有湿润棕色泥土,表面平整
- 镜头内动作:一只手从画面右侧伸入,握住一把灰白色草木灰粉末,均匀撒到泥土表面,粉末轻微扬起
- 结束状态:花盆泥土表面覆盖一层薄薄的灰白色草木灰,呈不均匀分布

镜头 2 (5s):关键转变 - 拌入泥土
- 开始状态:花盆泥土表面有一层灰白色草木灰(承接镜 1)
- 镜头内动作:一只手从右侧伸入,握住一个小木勺,把表层泥土和草木灰搅拌均匀
- 结束状态:花盆里泥土和草木灰已混合,表面呈现均匀的灰棕色

镜头 3 (5s):完成 + CTA - 移栽幼苗
- 开始状态:花盆里混合好的灰棕色泥土(承接镜 2)
- 镜头内动作:一只手从右侧伸入,把一棵幼苗(根部带土团)轻轻放入花盆中央,屏幕字幕"防根腐"出现
- 结束状态:幼苗稳稳立在花盆中央
```

## 范例 B · 选题 "大蒜水自制天然杀虫剂"

```
【双锚定方案 · 3 镜 × 5 秒 = 15 秒】

═══ 视觉锚定 ═══

1. 场景背景:厨房灶台旁的木质操作台,远处虚化的灰色厨房瓷砖墙
2. 主体容器:一个 500ml 透明玻璃量杯,内有 300ml 清水,放在木板上
3. 拍摄视角:平视近景特写,9:16 竖屏画幅,量杯居中
4. 光线:窗边自然光,从左侧 45 度入射,柔和顺光
5. 色调氛围:清新明亮,白色和透明色为主

═══ 叙事锚定 ═══

📖 故事弧线:捣蒜 → 倒入水中泡 → 过滤后喷瓶喷叶

- 镜头 1 (5s):一只手从右侧伸入,用陶瓷蒜臼捣碎几瓣大蒜,大蒜碎渣特写,完成捣碎后手退出
- 镜头 2 (5s):一只手把蒜碎倒入量杯,水面泛起涟漪,蒜碎缓慢下沉,水开始变浑浊
- 镜头 3 (5s):一只手用细网筛过滤蒜水滤入透明喷瓶,屏幕字幕"驱蚜虫"
```

## 范例 C · 选题 "啤酒擦叶 = 天然营养剂"

```
【双锚定方案 · 3 镜 × 5 秒 = 15 秒】

═══ 视觉锚定 ═══

1. 场景背景:室内阳台绿萝盆栽特写,远处虚化的浅色窗帘
2. 主体容器:一片成年绿萝心形叶子(占据画面中央),叶柄和茎部清晰可见
3. 拍摄视角:正俯视近景特写,9:16 竖屏画幅,叶片占画面 70%
4. 光线:北窗自然漫射光,叶片表面无强反光
5. 色调氛围:鲜亮的叶绿色,辅以浅色背景

═══ 叙事锚定 ═══

📖 故事弧线:蘸啤酒 → 擦拭叶面 → 展示光泽 + CTA

- 镜头 1 (5s):一只手从画面下方伸入,把棉签蘸入啤酒玻璃杯,棉签吸饱啤酒后取出
- 镜头 2 (5s):棉签在绿萝叶片上轻轻擦拭(从叶尖到叶根缓慢滑过),完成擦拭后手退出
- 镜头 3 (5s):镜头停留在擦完的叶片上,叶片表面水分蒸发出现光泽,屏幕字幕"天然营养剂"渐入
```

## 双锚定方案的硬约束清单

无论选题是什么,以下约束必须同时满足:

视觉硬约束:
- [ ] 景别只能是近景或特写(禁止全景、远景、中景)
- [ ] **画幅必须是 9:16 竖屏**(适配抖音/小红书/视频号 + Seedance pro fast 输出)
- [ ] 视角 3 个镜头完全一致(禁止切换、推拉摇移)
- [ ] 主体容器/操作面 3 个镜头完全一致
- [ ] 背景 3 个镜头完全一致
- [ ] 光线 3 个镜头完全一致
- [ ] 默认无人物(手部最多从画外伸入)

叙事硬约束:
- [ ] **第 K 镜结束状态 = 第 K+1 镜开始状态**(物理状态承接)
- [ ] 3 个镜头组合起来能讲完一个完整的"配方/动作流程"
- [ ] 每镜动作在配方流程里都有明确的功能性意义(不是"摆拍")
- [ ] 主体物品的形态变化必须有可解释的过程(不能从 A 跳到 C)
- [ ] 如果存在时间跳跃,必须用字幕明示("3 天后"/"静置 24 小时")

## 双锚定方案 → 生图 Prompt 的转换示例

> **重要:Seedream + Seedance 是字节自研模型,中文优化显著优于英文。所有 prompt 一律用中文写**。

以范例 A 的镜头 1 为例,生图 prompt(中文)应该是:

```
特写镜头,45 度俯视,9:16 竖屏构图。

背景:户外木质阳台,远处虚化的绿色阔叶植物。

主体:一个 15cm 直径的红陶素烧花盆,内有 80% 满的湿润棕色泥土,放在浅色木板桌面上。花盆居中,占画面 65%。

光线:正午柔和散射阳光,无强方向光,无明显阴影。

色调:温暖土系色调,黄棕色为主,叶片绿色为辅。

本镜的可变元素 - 起点状态:
泥土表面平整、未被扰动 — 这是撒草木灰之前的状态。

高画质,真实摄影风格,无文字,无水印,自然光。
```

镜头 2 的 edit prompt(传 `image` 字段把镜头 1 作为参考图,基于它做编辑)按"改 / 承 / 锁"三段式:

```
把泥土表面从未扰动的棕色,改成上面均匀撒了一层薄薄的灰白色草木灰粉末(分布不均,有薄有厚)。

关键:状态必须从上一镜自然承接过来:
- 还是同一个红陶花盆放在同一位置
- 还是同一片浅色木板桌面和虚化的绿色植物背景
- 还是 45 度俯视和 9:16 竖屏
- 还是正午柔和阳光和土系暖调

以下要素严格保持完全一致,不要改动:
- 一样的红陶花盆在同样位置
- 一样的木板桌面和虚化绿植背景
- 一样的 45 度俯视角和 9:16 竖屏
- 一样的柔和正午光和土系暖调
- 一样的构图和景深

只改这一处:泥土表面现在有了一层草木灰(这就是镜头 1 的结束状态,也是镜头 2 的开始状态)。
```

镜头 1 的 motion prompt(给火山 Seedance 1.5 pro):

```
一只手从画面右侧边缘伸入,手里握着一把灰白色草木灰粉末。手缓慢地把粉末均匀撒到花盆里的棕色泥土表面上,细粉末粒子在空气中轻微飘散。结束时手从画面右侧退出,留下泥土表面薄薄一层不均匀的草木灰。画面锁定,不推不拉不摇不移。自然光不变,背景不变。
```

api_client.py 会自动在末尾追加(**保留英文,这是模型协议关键字**):`--resolution 1080p --ratio 9:16 --duration 5 --camerafixed true --watermark false`

api_client.py 还会自动追加音频指令(基于 `--voice-preset` 拼接,默认 friendly-girl):`音频:AI 年轻、清亮、亲切、带一点轻松笑意的声线女声口播,情绪轻松友好,像跟朋友分享小窍门,语速中速自然,不刻意拖长,台词:'撒草木灰,防根腐'`

---

这种格式是 skill 在 Stage 2-3 应该产出的内容。具体到每次任务,所有内容由 agent 根据当次选题动态生成,**不复用本文档的具体描述**。
