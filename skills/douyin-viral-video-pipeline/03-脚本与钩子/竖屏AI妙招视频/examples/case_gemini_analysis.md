# 参考案例:三农 AI 视频对标拆解

> ⚠️ **重要说明**:这份文档是为了给 skill 的选题阶段和视觉锚定阶段提供**灵感**和**结构参考**。
> 它同时是 **Stage 1.2「对标拆解」的目标产出形态**——用户上传对标视频时,agent 抽帧分析后
> 应该产出一份类似结构的拆解报告(镜头编排 / 视觉设定 / 文案公式 / 可借鉴 vs 不要照搬)。
>
> **不要把这份文档的具体内容当成模板照搬。** 每次生成视频时,视觉风格(背景/容器/视角/光线)都要根据当次的选题重新跟用户对齐确认。本案例取自三农题材,其他题材拆解结构相同。

---

## 案例概述

- **赛道**:三农 / 阳台种菜 / 园艺小妙招
- **时长**:11 秒(原案,AI 生成)
- **目标受众**:喜欢种菜养花的中老年人群 / 都市白领
- **带货方向**:农资化肥(液态肥/营养液/生根粉/杀虫剂)、园艺工具

## 视觉拆解(原案的具体设定)

> 仅作灵感参考。实际项目里的视觉锚定方案要按 SKILL.md Stage 2 跟用户重新对齐。

- **场景**:绿意盎然的菜地/大棚(黄瓜藤),展现"生机勃勃"的种植结果
- **核心道具**:复古木桶 + 木勺(田园原生态感,比塑料桶更有视觉暗示)
- **镜头编排**:
  - 镜头 1:特写,味精倒入木桶,木勺搅拌
  - 镜头 2:特写,倒入红糖,水变色
  - 镜头 3:特写,倒入啤酒
  - 镜头 4:中景/近景,人物出镜手持白醋倒入,微笑看镜头
- **字幕风格**:底部居中大字,白字 + 黑边或加粗阴影

## 文案公式

```
[厨房常见日用品] + [兑水/简单处理] = [专业农资效果]
```

原案 4 句:
1. 味精兑水就是天然化肥
2. 红糖兑水是生根剂
3. 啤酒兑水就是营养剂
4. 白醋兑水去黄叶
5. (CTA)记不住就点赞收藏哦

## 爆款逻辑(可迁移到其他选题)

1. **认知反差**:把原本需要花钱买的专业农资,替换成家家户户都有的厨房用品 → 触发"省钱小妙招"心理,极易转发收藏
2. **超高信息密度**:11 秒里输出 4 个知识点 → 观众走神就错过,必须点收藏或看第二遍 → 高完播率 + 高复播率
3. **为带货做铺垫**:虽然教的是"土办法",吸引来的是 100% 精准的种植人群 → 后续可挂车专业产品(话术:"觉得自己配麻烦的,直接用左下角这款配好的 XXX")

## 这个 skill 在原案基础上做的调整

### 时长:11s → 15s(直出可用)

**原因**:火山 Seedance 1.5 pro 标准单镜时长是 5 秒,3 镜 × 5s = 15s,**直出可用,不用剪映砍剪**。**额外加分:Seedance 1.5 pro 自带 AI 女声配音**,口播文案直接变成视频音轨,剪映里不用再加配音。

跟原案 11s/4 镜的"极致快剪"风格相比,本 skill 是 15s/3 镜的"中速快剪"。每镜从 2.75s 拉长到 5s,**单镜动作更从容,适配信息量更密的配方教学**,完播率窗口也更友好(抖音/小红书 15s 是热门窗口)。

### 4 个知识点 → 3 个知识点

**原因**:时长压缩 + 镜头数减少导致。

**应对**:
- 第 1 镜 = 配方制作起点(原料/容器准备)
- 第 2 镜 = 关键转变(混合/浸泡/过滤)
- 第 3 镜 = 完成 + CTA(成品/使用/字幕引导互动)

实践中 3 个知识点足够支撑一条带货短视频,信息密度可以通过画外音补充。

### 镜头 4 的"人物中景出镜" → 默认不做

**原因**:Seedance 1.0 pro fast 在跨镜头身份一致性上受限。原案里第 4 镜从特写跳到人物中景,主体/景别都变了,跨镜一致性容易翻车。

**应对**:**默认全程特写锁机位**,人物表达走画外音 + 字幕。

如果用户**坚持**要人物出镜,可以放开,但提示用户:
- 可能需要多次重试
- 建议人物镜头放最后,作为"露脸 + CTA 复合镜"
- 人物画风要明确,避免"小红书白人女孩"的 AI 通病

### 画幅:1:1 方画幅 → 9:16 竖屏

**原因**:本 skill 用火山 ARK Seedance,通过 `--ratio 9:16` 参数控制输出竖屏。9:16 是抖音/小红书/视频号的主流尺寸,比 1:1 更适配发布平台。

### 视觉模板不固定

**原案的木桶 + 菜地不是模板**。skill 会根据选题反推合适的视觉锚定方案,例如:

| 选题方向 | 可能的视觉锚定 |
|---------|--------------|
| 草木灰防根腐 | 俯视红陶花盆 + 拌土特写(9:16 竖屏) |
| 大蒜水驱蚜虫 | 玻璃杯捣蒜 + 喷瓶喷叶特写 |
| 啤酒擦叶子 | 绿叶特写 + 棉布蘸啤酒擦拭 |
| 鸡蛋壳粉补钙 | 砸碎的鸡蛋壳 + 小钵研磨 |
| 香蕉皮埋根 | 土表特写 + 香蕉皮切块 |

每次都重新对齐,不复用上一次的视觉设定。

## 不要照搬的部分

❌ **不要复用木桶 + 菜地的视觉**(变成一眼假的复制粘贴爆款)
❌ **不要复用味精/红糖/啤酒/白醋这一组**(平台算法会判定为"重复内容")
❌ **不要把"记不住就点赞收藏"当唯一 CTA**(可以换成"想试试的扣 1"、"评论区告诉我你的菜"等)
❌ **不要追求 11s/4 镜的极致快剪**(Seedance pro fast 单镜最短 5s,强行模仿会牺牲画面质量)

## 可以参考的部分

✅ **公式结构**:[低成本日用品] + [简单处理] = [专业效果]
✅ **信息密度逻辑**:每镜一个独立知识点(3 镜 = 3 个知识点)
✅ **结尾 CTA 模式**:最后一镜固定是引导互动
✅ **视觉一致性原则**:全程同一个场景 + 同一个主体容器 + 只换"动作中变化的元素"
✅ **叙事连贯性原则**:每镜的结束状态 = 下镜的开始状态,3 镜串成完整流程
✅ **字幕样式**:白字 + 黑边 + 居中偏下
