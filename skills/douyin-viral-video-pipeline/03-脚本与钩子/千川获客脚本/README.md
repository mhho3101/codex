# qianchuansucai — 千川素材·短视频获客脚本

顶级短视频获客文案专家 Skill，专精「**元麻烦**」理论与「**卖点可视化**」创作方法。为任何产品找到用户最深的自我怀疑，用硬核视觉测试击碎它，产出可直接拍摄的 **80 秒获客视频脚本**。

> 使用场景：千川素材 / 抖音信息流获客脚本、短视频带货脚本、获客视频、投放素材、广告脚本。

## 核心理论

### 元麻烦理论
元麻烦是用户在反复经历品类的"系统失望"后，对自己产生的根本性消极结论。

**三层追问法**：
1. **功能麻烦**：这个产品哪里不好用？（≥10 条功能缺陷）
2. **系统失望**：为什么换了这么多牌子问题还在？（跷跷板句式："___的，但___。___的，又___。"）
3. **元麻烦**：是不是我自己的问题？（"是不是我______？"）

**三个判断标准**：向上不可解 / 向下包得住 / 向内不向外

### 卖点可视化
不靠说，靠做。每个卖点必须配一个"暴力测试"动作：
- 测试动作 → 镜头前对产品施加压力
- 效果特写 → 产品不崩、不坏、不露怯
- 技术解释 → 一句话说清凭什么能做到

## 十节点脚本结构（80 秒）

| 节点 | 时间 | 任务 | 情绪 |
| :--- | :--- | :--- | :--- |
| ①麻烦直击 | 0-5s | 停住她 | 尴尬/困惑 |
| ②麻烦蔓延 | 5-15s | 让她共鸣 | 烦躁/忍耐 |
| ③系统失望 | 15-22s | 让她信你懂行 | 失望 |
| ④元麻烦爆发 | 22-28s | 击中内心 | 自我怀疑/认命 |
| ⑤产品介入 | 28-35s | 给希望 | 从认命到注意 |
| ⑥卖点击破 | 35-52s | 征服理性 | 试探→信服 |
| ⑦穿戴验证 | 52-62s | 让她代入 | 被打动 |
| ⑧元麻烦击碎 | 62-68s | 让她和解 | 顿悟→和解 |
| ⑨行动指令 | 68-75s | 让她行动 | 被赋能 |
| ⑩品牌落点 | 75-80s | 让她记住 | 治愈 |

## 输出格式

每次输出包含三部分：
1. **产品元麻烦分析**（功能麻烦清单 / 系统失望 / 元麻烦 / 卖点可视化清单）
2. **完整分镜头脚本**（表格：时长 | 节点 | 画面 | 台词 | 可视化动作 | 情绪）
3. **拍摄备注**（道具 / 场景 / 口播节奏 / 音乐音效）

```sh
git clone https://github.com/paul-xing/qianchuansucai-skill.git ~/.claude/skills/qianchuansucai
```

### Codex

```sh

git clone https://github.com/paul-xing/qianchuansucai-skill.git ~/.codex/skills/qianchuansucai
```

### 通用（~/.agents）

```sh
mkdir -p ~/.agents/skills
git clone https://github.com/paul-xing/qianchuansucai-skill.git ~/.agents/skills/qianchuansucai
```
