# 数据复盘指南

## 指标

1. 首 3 秒留存率
2. 7 秒留存率
3. 平均播放时长
4. 完播率
5. 互动率
6. 收藏率
7. 转化率

## 诊断

- 首 3 秒掉得快：钩子不够具体、画面缺乏变化或开场信息模糊。
- 3-7 秒掉得快：钩子与正文衔接失败，用户没有快速获得价值。
- 中段掉得快：信息重复、解释过长或镜头缺少变化。
- 结尾掉得快：CTA 太长，结论已经结束。
- 播放高、互动低：信息有吸引力，但缺少观点、情绪或实用价值。
- 收藏高、关注低：内容工具性强，但个人定位不够鲜明。
- 点击高、转化低：承诺与实际内容或产品不一致。

## A/B 原则

一次只修改一个变量。可测试钩子、第一镜头、封面文字、口播语速、CTA、视频时长。
