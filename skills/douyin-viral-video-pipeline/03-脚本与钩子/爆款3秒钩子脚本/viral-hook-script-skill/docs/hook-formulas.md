# 钩子公式

## 反常识型

大家以为 X，真正决定结果的是 Y。

示例：大家以为 AI 难学，真正难的是提需求。

## 痛点型

还在做 X？你可能正在失去 Y。

示例：还在手写教案？你可能浪费了备课黄金时间。

## 数字型

只用 X 分钟，完成 Y。

示例：只用 20 分钟，搭好一节课框架。

## 悬念型

我做了 X，结果最意外的是 Y。

示例：我让 AI 改教案，最意外的是这一句。

## 冲突型

你一直坚持的方法，可能从第一步就错了。

示例：你一直套模板，可能第一步就错了。

## 身份型

如果你是 X，这一步必须先做。

示例：如果你是老师，先别急着写教案。

## 结果前置型

这套流程，让原来 X 的工作缩短到 Y。

示例：这套流程，把两小时备课压到二十分钟。

## 错误警告型

做 X 之前，先停止这 N 个动作。

示例：让 AI 写脚本前，先停止这三个动作。
