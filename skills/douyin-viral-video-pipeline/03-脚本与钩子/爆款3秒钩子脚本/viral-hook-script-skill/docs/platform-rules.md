# 平台规则

## 视频号

- 可信、自然、专业。
- 节奏中快，避免过度表演。
- 适合知识、教育、经验分享。
- 可保留适度情绪和个人故事。

## 抖音

- 前 3 秒必须有明显刺激点。
- 结果前置，价值尽早出现。
- 镜头平均 0.8-2 秒。
- 字幕要短，动作要明确。

## 小红书

- 强调真实体验、审美和细节。
- 适合清单、避坑、过程记录。
- 镜头可 2-5 秒。
- 封面文字必须明确利益点。

## B站

- 允许更完整论证。
- 强调逻辑、案例、过程。
- 镜头可更稳定。
- 信息结构必须清楚。

## TikTok / Reels

- 优先视觉动作。
- 字幕简短。
- 钩子尽量脱离声音也成立。
- 避免复杂背景知识。
