# 示例三：摄影

## 输入

- 主题：拍领导肖像时最容易犯的三个错误
- 平台：视频号
- 输出：30 秒脚本和分镜
- CTA：关注

## 30 秒口播稿

拍领导肖像，最容易错在三个地方。第一，机位太低，会让面部变形；第二，光太硬，皱纹和疲态会被放大；第三，背景太杂，人物气质会被削弱。正确做法是镜头略高于眼睛，主光柔一点，背景只保留和身份相关的元素。想拍得稳重自然，先把这三点做好。
