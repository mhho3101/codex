# 脚本结构与四关校验（模块 C 用）

## 起草顺序（先查库，再动笔）

1. **步骤 0 · 查阅模式库**（必做）：打开 `references/copy-patterns.md`，按选题类型找匹配的公式/钩子句式/金句模板。翻录对标视频时先读该对标的拆解结论。不要凭空写。
2. **选公式**：从八大爆款公式选一个（痛点+解法/反常识/数字钩子/对比冲击/扎心真相/隐喻比喻/对仗金句/反问触发）——按素材特点选，不按心情选。
3. **套结构**：长口播用下方"通用获客脚本结构"；20-40 秒短口播用"黄金结构"（copy-patterns.md §B）。
4. **成稿 → 过四关**（见下）。

## 通用获客脚本结构

```text
标题：【目标客户】已经在【场景】投入了成本，但【结果】还没出来

前 3 秒（钩子）：
推荐页＝所选钩子体套本选题痛点；搜索页＝第一句直接给结论；白描体＝真实细节直给。

问题：点出一个极刚痛点——客户知道重要、自己判断不了、判断错代价很大。
解法：按"错在哪 → 为什么 → 怎么做"给思考路径（不急着给标准答案）。
小切口方案：给一个今天就能用的小方法，证明你是内行，但不把系统问题全解决（留下咨询缺口）。
证据：现场/案例/流程/数据——必须有真实来源。
服务逻辑：顺手讲清你服务谁、解决什么问题、为什么适合找你。
结尾转化：一个明确动作——评论【关键词】/ 私信【资料】/ 发【图纸、场景、预算、现状】。
```

## 八类获客选题模板

| 类型 | 结构 | 适用 |
| --- | --- | --- |
| 一条讲清型 | 【结果】到底怎么做？一条视频讲清 | 方法论/系统搭建 |
| 误区纠偏型 | 你以为【A】重要，其实客户看的是【B】 | 破错误指标 |
| 低门槛结果型 | 你只要做到【低门槛指标】，也能有【结果】 | 给执行者信心 |
| 付费时刻型 | 客户什么时候会愿意为【服务】付费？ | 高客单/咨询类 |
| 行业迁移型 | 【行业】怎么拍获客视频？先抓这 3 个问题 | 定制方案 |
| 评论反推型 | 评论区都在问【问题】，说明客户真正想要【需求】 | 复盘追更 |
| 标准清单型 | 找【供应商/服务】前，先问清这 5 件事 | B2B/采购/服务业 |
| 承接闭环型 | 视频火了没用，私信接不住也白搭 | 账号系统搭建 |

## 四关校验 v2（过不了不算定稿）

> 前二关可跑 `python scripts/director.py check <脚本文件> [--client <cid>]` 确定性校验；有客户专属标准卡时加 `--client` 读取 06-standard.md 的「机判校准」区（句长上限/动词表/开场/收尾按客户成片实测），无校准则回退通用规则。钩子关与逻辑关由 Agent 按本卡执行。

### 钩子关（居首）

- [ ] 开头确实用了所选钩子体且套中本选题痛点。搜索页＝首句直接给答案；白描体＝首句细节真实、具体、别处抄不走。
- [ ] **攻击性/冲击力**（v2 新增）：钩子不是"正确但安全"的说教。自检：如果换成"醒醒吧/你知不知道/活该"类表达会更有停留欲，说明现钩子太温和。
- [ ] 字数 5-15 字，一眼有悬念。

### 格式关（机器可判）

- [ ] **句长**：每句 ≤15 字（不含标点）。
- [ ] **禁用词**（书面腔）：进行/实施/开展/针对/关于/由于/因此/一定要/必须要/应该要/需要注意的是/所谓/即/亦/其/之/而/则/予以/给予/能够/可以说/在于/对于/通过/使得。
- [ ] **人称**：用"你/自己"，不用"我们/人们/一个人"。
- [ ] 总字数匹配时长：20 秒≈80 字，30 秒≈120 字，40 秒≈150 字。

### 结构关（机器可判）

- [ ] **开头词合格**：记住/真正的/一个残酷的真相/别再/停止/从今天起/听好了/醒醒吧；禁用：你知道吗/你有没有想过/你是否/今天我们来聊聊/很多人不知道/其实。
- [ ] **行动词 ≥2 个**：学习/研究/重复/实践/观察/放下/开始/练习/尝试/改变/停止/接受/拒绝/专注（"拥有/成为/变得"不算动作）。
- [ ] **收尾合格**：用"先从 X 开始/记住这种感觉/从今天起"+具体动作；禁用"去吧/加油吧/相信自己吧/你会变得更好/一切都会好起来"。
- [ ] 获客脚本另需：钩子/问题/解法/小切口/证据/转化六段完整。

### 逻辑关（三关系检查法，Agent 执行）

对每对相邻句 A→B，三者至少满足一个，否则重写后句：

| 关系 | 检验句式 |
| --- | --- |
| 原因 | "因为 B，所以 A" 说得通？ |
| 结果 | "因为 A，所以 B" 说得通？ |
| 具体化 | "A，具体来说就是 B" 说得通？ |

执行：给每句编号 → 逐对检查 → 三者全否＝逻辑断裂，重写后句 → 重检。

示例（三关系检查）：

| 句对 | 检查 | 判定 |
| --- | --- | --- |
| "自信是练出来的"→"大量学习，大量研究" | "练出来的"具体就是"学习研究"（具体化） | ✅ |
| "对一切祛魅"→"先从厌弃看不起你的人开始" | 三关系全否（祛魅≠厌弃，概念偷换） | ❌ 重写后句 |
| 改为"先从不在意别人的评价开始" | "祛魅"具体就是"不在意评价" | ✅ |

`director.py check <文件>` 会输出编号句，供逐对判断。

## 发布前一票否决

脚本卡的「真实素材来源」栏填不出来源（采访记录/现场拍摄/客户真实数据）＝案例数字是编的，**直接打回，不进四关**。

## 常见错误清单

- 只讲干货，没有目标客户点名。
- 只追播放量，结尾没有线索入口。
- 一上来证明自己专业，没有先描述客户已付出的代价。
- 试图把系统问题一次讲完，没有留下付费咨询缺口。
- 结尾只说"关注我"，没让用户交出下一步信息。
- 讲道理不写共鸣：全是"别 XX"的命令式说教，没有"卧槽说的就是我"（v2 新增）。
- 抽象无画面：没有具体场景/动作/时间限定（v2 新增）。
- 多条金句无过渡词，直接跳转（v2 新增）。
