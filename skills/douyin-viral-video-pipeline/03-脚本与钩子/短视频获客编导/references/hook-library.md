# 钩子库 · 23 类爆款开头体（模块 B 用）

> 用法：选一类钩子体 → 套该客户痛点 → 写出开头 3 秒。
> 纪律：对立冲突类（1/2/7/10/11/22）同一客户连续 3 条不得重复；信任实证类（4/12/15/17/18/20/23）占比 ≥40%。
> 格式说明：每类下的「通用：」行是 `director.py assemble` 的自动装配素材；给客户用时必须替换为该客户真实痛点，禁止直接照搬。

## 1. 范式宣告体（「X 已死，Y 已来」）
- 机制：制造时代交替感，让人怕错过。
- 通用：「『砸钱投流』已死，『内容获客』已来。」

## 2. 反差打脸体（沉没成本 / 认知被颠覆）
- 机制：先承认对方的投入，再指出方向错了。
- 通用：「你天天发视频没人看，问题往往不在拍，在选题。」

## 3. 筛选清单体（数字 + 只留精华）
- 机制：用数字承诺信息密度，降低点开成本。
- 通用：「90% 的获客视频，死在开头这一句。」

## 4. 权威背书体（大神 / 数据 / 机构在用）
- 机制：借第三方权威降低信任成本；背书必须真实可查。
- 通用：「头部同行都在偷偷用的选题结构。」

## 5. 痛点共鸣体（说出用户没说出口的话）
- 机制：把用户心里有但没说出口的尴尬说出来。
- 通用：「不是不想拍，是打开剪辑软件就不知道说啥。」

## 6. 结果先行体（先甩强结果承诺）
- 机制：先给结果再给过程；承诺必须可兑现，禁夸大。
- 通用：「一条视频讲清：能获客的短视频到底怎么做。」

## 7. 反常识金句体（一句话掀桌）
- 机制：推翻一个默认认知，制造"啊？"的瞬间。
- 通用：「客户多少，和你的粉丝量没有任何关系。」

## 8. 一站式全家桶体（一个方案吃掉整条流水线）
- 机制：击中"工具太多、流程太碎"的疲惫感。
- 通用：「选题、脚本、排期、复盘，一套流程全管了。」

## 9. 极简碾压体（越少越强 · 小东西干掉大家伙）
- 机制：用"小"反衬"贵/重"的浪费。
- 通用：「一张表，干掉你手机里 8 个运营群。」

## 10. 否定表层·指向系统体（你缺的不是 X，是 Y）
- 机制：把表层焦虑重新归因到系统问题。
- 通用：「你缺的不是剪辑技巧，是一套选题系统。」

## 11. 反讽警示体（想毁掉 X，就让他一直 Y）
- 机制：反着说，讽刺感制造传播；注意分寸别引战。
- 通用：「想毁掉一个账号，就让他每天追热点。」

## 12. 代价背书体（我花 X 代价换来的，直接给你）
- 机制：用已付出的代价证明内容含金量；代价必须真实。
- 通用：「踩了三个月坑换来的排期表，直接给你。」

## 13. 信息差体（90% 的人都不知道）
- 机制：制造"看到即赚到"的信息差感；内容必须真的少有人讲。
- 通用：「90% 做企业号的人，没开过这个后台开关。」

## 14. 损失厌恶体（早点看到，能少走弯路）
- 机制：激活"怕亏"心理；不要编造损失案例。
- 通用：「这条要是早半年看到，能少烧五万代运营费。」

## 15. 真实复盘体（上线第 X 天炸了 / 我踩过的坑）
- 机制：失败复盘天然高信任；必须是真实经历。
- 通用：「起号第 30 天，数据归零，我复盘出 3 个错。」

## 16. 顿悟暴论体（录完才悟到 / 我有个暴论）
- 机制：用"顿悟"姿态输出强观点；暴论要自圆其说。
- 通用：「我有个暴论：企业号根本不该追爆款。」

## 17. 现场纪实体（我去 X 现场 + 评论区扣 1）
- 机制：第一人称真实现场，B 端强获客；要有真实素材。
- 通用：「昨天去客户现场交付，全程拍给你看。」

## 18. 天花板被捅破体（权威/原厂下场 + 硬指标坐实）
- 机制：用硬指标宣告行业变化；指标需可查证。
- 通用：「官方亲自下场，这个行业的玩法变了。」

## 19. 零门槛反差体（不会 X 也能 Y）
- 机制：消除"我不会"的心理门槛。
- 通用：「不会写文案，也能把企业号做起来。」

## 20. 完整系统拆解体（拿真实案例拆碎讲）
- 机制：展示系统能力而非单点技巧，拉开专业差距。
- 通用：「把一个 30 天涨粉 2 万的账号，拆碎了讲。」

## 21. 免费平替体（我嫌 X 太贵，自己做了个免费的）
- 机制：用免费替代品换评论/私域入口；适合起号期。
- 通用：「代运营报价三万，我做了个免费版流程送你。」

## 22. 反共识唱衰体（大家都在追的 X，其实是陷阱）
- 机制：逆向断言撬争议转发；必须给得出新视角，否则反噬信任。
- 通用：「都在追的这个风口，普通企业其实吃不到。」

## 23. 白描纪实体（无套路开头 · 钩子豁免通道）
- 机制：这不是套路，是**豁免通道**——手里有客户真实素材（现场/原话/具体数字）时，不用前 22 类任何钩子，用高密度真实细节开场，让观众自己推导结论（"我指给你看"）。
- 规则：开头 3 秒必须是只有这个客户才知道的具体细节；"最近很多人问我"式伪白描一律打回；仍须过评分闸门与回标。
- 通用：无模板可套——它的全部价值就在"这条细节编不出来"。

## 标题装配公式（选完钩子后把标题配满）

命中越多越抓人：具体数字 / 时间锚 / 「已死已来」对立 / 「被一个 X 干掉」降维 / 「决定你上限·第一步」因果断言。

## 搜索页通道（钩子豁免的另一出口）

面向搜索流量的选题不套钩子：标题带用户真实搜索词（平台搜索下拉联想 + 创作者中心搜索分析取词），开头第一句直接给结论/答案再展开；同主题做系列化（统一关键词前缀），提升账号垂直度与长期检索命中。
