# 策划诊断（模块 A · 新客户接入，只做一次）

> 目标：把"一个客户"变成"一个可运营的账号系统"。顺序不可乱：先定位，再选题；先小步验证，再放量。

## A1. 客户路由与目标审计

先问清三件事（问用户，不问客户幻想）：

1. **商业任务**：这个账号要品牌曝光、咨询线索、私域加粉，还是预约转化？只选一个主目标。
2. **目标客户**：不是"老板"，是"正在遇到什么具体问题的什么人"（角色 + 场景 + 付费时刻）。
3. **转化动作**：用户看完视频后做什么？评论什么关键词 / 私信什么 / 留什么资料？

商业诊断输入工具：`templates/discovery-questionnaire.md`（产品阶梯/目标客户/体量基线/转化路径/交付能力/竞品/内容历史七问，采访前发客户填）。

## A2. 采访挖素材（拿到真实弹药）

不采访不出题。采访别问"你怎么看"（只会得到正确但平的观点），要问出故事：

- **顶级样本 + 反常识结果**：「你服务过最好的客户，当初是什么情况？」
- **数字敏感 + 故事 + 情绪**：「第一次签下大单是什么时候？怎么做到的？当时什么感受？」
- **对比 + 同类人群**：「懂行的客户和不懂行的客户，差别在哪？」
- **奇怪现象 + 深度归因**：「这个行业有什么外行人不知道的潜规则？」

把客户原话记下来——原话就是最好的选题库和钩子句来源。

## A2.5 合成定位卡（v2 新增）

> 每一步的方法依据见 `references/positioning-patterns.md`（定位模式库：四维/公式/人设放大法/差异化两路径/客群拆解/起号三目标/场景三传递/变现路径）。定稿前过该卡 §J 定位验证清单。

把 A1（目标审计）+ A2（采访原话）合成一张定位卡（模板见 `templates/positioning-card.md`），六个模块：

1. **账号人设**：客户是谁——身份 + 信任状 + 反差（从采访原话提炼）；
2. **目标观众**：角色+场景+付费时刻（A1 结论）；
3. **差异化假设**：凭什么只有他讲才成立（该客户的潜在 Aha Moment 候选）；
4. **内容主线**：讲哪几个方向（从原话提炼）；
5. **转化动作**：评论关键词/私信话术（A1 结论）；
6. **体量预期**（内参，不给客户）：产品阶梯×转化率×体量基线的收益倒推。

定位卡发客户确认；**客户没确认前不进入选题**——写进代办，定时催办（见 `references/persistent-loop.md` §挂起）。

## A3. 建客户五件套

跑 `python scripts/director.py onboard <id> <名称> <行业> <CTA关键词>`，自动创建 `clients/<id>/` 五个文件（总控台/选题库/脚本库/对标库/学习日志）。把 A1/A2 的结论填进总控台。

## A4. 初始选题池（30-50 条）

**冷启动选题来源（v2 补充）**：首轮没有客户数据，选题三个来源——
1. **联网搜索**：行业关键词/热点/客户相关话题；搜索词构造＝行业核心词 × 痛点词（怎么办/避坑/多少钱/选哪家）× 场景词（第一次/踩坑/对比）；
2. **对标研究**：公开对标账号的高互动内容（见 `references/standard-mining.md` 成对样本区）；
3. 从搜索结果提取「真实需求/常见误区/典型案例」三类入词表（可标来源链接，不允许脑补）。

用连连看矩阵出第一池：`python scripts/director.py matrix <id>`。
先编辑 `clients/<id>/matrix.json` 填词表（词表只能来自采访原话、评论区真实提问、搜索下拉联想、上述搜索结果——不允许脑补）：

- **行业核心**（1 个）：客户的行业/产品
- **行业相关**（8-12 个）：细分领域、常见问题、关键决策点
- **人群/场景**（10-15 个）：会接触这个行业的人或场景

矩阵产出后按痛点/误区/案例/流程/对比/FAQ/产品场景分类，过评分闸门（见 `references/scoring-gate.md`），留下 30-50 条进选题库。

## A5. 试跑验证（2-4 周）

- 小批量拍 10-15 条，不追爆款，验证三件事：内容方向对不对、执行节奏稳不稳、线索质量高不高。
- 试跑期每周看一次：有效咨询数、评论内容质量、完播率；不看绝对播放量。
- 试跑结论只有三种：方向对→放量；方向偏→换选题角度再来一轮；承接断→先修私信/评论话术。

## A6. 自查清单（策划段验收）

- [ ] 商业任务只有一个主目标
- [ ] 目标客户写到"角色+场景+付费时刻"颗粒度
- [ ] 有采访原话记录（不是二手转述）
- [ ] 选题池 ≥30 条且全部过评分闸门
- [ ] 试跑计划写清了验证指标和时间窗
- [ ] 定位卡过了 `references/positioning-patterns.md` §J 验证清单
