# 文案模式库（钩子 / 结构 / 金句 / 过渡）

> 用途：模块 C 起草脚本前"步骤 0"查阅。全部句式去客户化、行业无关，跨客户只复用「XX」模板本身。
> 用法：先按选题类型找匹配模式，再按本库取句式；套进模板后必须过四关校验（`script-structure.md`）。
> 本卡是**单一正本**：新句式先沉淀到本地带证据的生长库，发行时提炼通用部分回本卡（去客户化、去行业专属）。

## B. 黄金结构（20-40 秒短口播）

```text
命令式开头（"记住/真正的XX是/一个残酷的真相"）
  → 行动链条（动作1→动作2→动作3，短句连击，3-4字一顿）
  → 情感三连（动词+自己 ×3 递进，如"欣赏自己，期待自己，爱上自己"）
  → 反常识金句（打破常规认知）
  → 行动锚点（"先从X开始，记住这种感觉"）
```

禁忌：问句开头（"你知道吗"像考试）、概念解释腔（老师讲课感）、鸡汤收尾（"去吧/会好的"）。

## B2. 五段式（3 分钟长口播 ≈800 字）

钩子+信任建立（场景引入→好奇问题→信任事实→三层提问预告）→ 开场白 → 逐层讲解（用"那聪明的你肯定想到了"串联）→ 总结+一条可执行建议 → 收尾关注引导。

## B3. 三大内容线（生活/产品类通用）

1. **情绪生活方式线**：生活片段 → 情绪治愈 → 产品成为陪伴物 → 共鸣式结尾。
2. **知识/避坑收藏线**：权威/反常识 → 清单 → 一句话解释 → 收藏引导。
3. **产品/可视化线**：动作/反差展示 → 痛点对比 → 技巧收束。

## D. 金句压缩（删到不能再删）

| 技巧 | 示例 |
| --- | --- |
| 删虚词（的/了/着） | "当你能够观察自己的情绪的时候" → "能观察情绪，你就在情绪之外" |
| 删强调词（一定要/必须） | "一个人一定要学会管住自己的嘴巴" → "守嘴不惹祸" |
| 长句拆短句 | "那些想要吃掉你的人往往说话更动听" → "想吃你的人，比保护你的人说话更动听" |
| 书面换口语 | "由于/因此/能够" → "因为/所以/会" |

检验：能不能一口气读完？读完有没有节奏感？

## E. 过渡技巧（多条金句必用）

- **数字序号法**（推荐）：第一，…第二，…第三，…
- **递进式**：首先，…不仅如此，…更重要的是，…最关键的，…
- **对比式**：有人说…但真正厉害的人…因为他们懂得…
- 禁忌：无过渡直接跳转（观众懵圈）。

## F. 共鸣写法六要点（区分"能看"和"爆款"）

1. **写共鸣不写道理**：道理=正确的废话；共鸣="卧槽说的就是我"。
2. **钩子要有攻击性**："管不住嘴的人，活该被人卖" > "守嘴很重要"。
3. **每条都要有画面感**：加场景（饭桌上）、动作（当段子讲）、时间限定（三天之内）。
4. **全程用"你"**：被点名的感觉 > 第三人称隔靴搔痒。
5. **毒舌收尾**：金句后加一句狠的（"还纳闷怎么全世界都知道了？活该。"）。
6. **结尾要有态度**："嘴严的人，运气不会太差。" > "祸从口出，病从口入"。

### 完整案例对比（说教版 vs 爆款版）

❌ 说教版：「守住嘴，就守住了一半的命。第一，别乱交底。你的秘密，说出去就是别人的把柄……记住：祸从口出，病从口入。」——钩子无攻击性、全是命令、无画面、无"你"。

✅ 爆款版：「你知道自己是怎么被卖的吗？就是你那张管不住的嘴。第一，你掏心掏肺说的秘密，转眼就成了别人饭桌上的笑话。还纳闷怎么全世界都知道了？活该。第二，你背后随口一句评价，三天之内，一定传到当事人耳朵里。别问我怎么知道的。……守嘴不是懦弱，是聪明。嘴严的人，运气不会太差。」——攻击性钩子+全程"你"+画面感+毒舌收尾+态度结尾。

## G. 收尾公式

- 行动锚点：「先从 X 开始，记住这种感觉。」
- 态度收尾：「听懂的人，已经在路上了。」「信不信由你。」
- 反转收尾：「越解释越心虚，沉默才是最狠的回击。」
- 轻 CTA 收尾：「看看你是哪一种」「评论 XX，后面专门拆」。

## H. CTA / 评论承接模型

| 阶段 | 承接方式 |
| --- | --- |
| 评论区 | 关键词报号（如「新手/送礼/选型」），关键词即私信入口 |
| 私信第一问 | 先问对象/预算/场景，再给建议（不直接推销） |
| 到店/活动 | 预约动作具体化：时间、场次、席位 |

## I. 合规红线（写之前必读）

- 健康/食品：不写治病、长寿、提高免疫力、降低得病几率。
- 课程/培训：不写包就业、包考证、证书含金量保证、月入过万。
- 玄学/命理：不写强暗示（不要划走/宇宙选中你/马上发财/必然转运），不做结果保证；发布前过对应合规审查。
- 通用：不造鄙视链、不贬低新手、不用绝对化（最好/第一/必治）、不蹭负面争议。
