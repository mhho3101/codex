# 发布排期与线索承接（模块 D 用）

## 排期纪律

1. **钩子限频**：同一客户连续 3 条不得重复使用对立冲突类钩子（1/2/7/10/11/22）；信任实证类（4/12/15/17/18/20/23）占比 ≥40%。
2. **两条腿走路**：收藏型内容（清单/干货/拆解）做信任沉淀，互动型内容（强 CTA/争议）做起量与私域——不要全发同一种。
3. **搜索系列化**：同主题做系列（统一关键词前缀，如"XX 避坑第 N 期"），提升账号垂直度与长期搜索命中。
4. **节奏稳定 > 频率高**：每周能稳定发 3 条，好过心血来潮日更一周然后断更。

## 发布前清单

- [ ] 四关校验已过（见 `references/script-structure.md`）
- [ ] 真实素材来源已填写

- [ ] 话题标签带行业长尾词（不只蹭热点词）
- [ ] 结尾 CTA 只有一个明确动作
- [ ] 评论承接话术已写好（见下）
- [ ] 预测表现已记录（盲打分，供回修对照）

## 评论承接话术（发布前就写好）

```text
视频 CTA：评论【关键词】，我发你一份【清单/自查表】。

自动/人工回复：
收到。你是做什么行业的？目前最想解决的是【选项 A】还是【选项 B】？

二次追问：
方便的话发我 3 个信息：
1. 你的产品/服务
2. 客户一般是谁
3. 你最想让客户咨询什么

承接动作：
我先按你的行业给你拆 3 个方向。适合的话，再帮你做完整方案。
```

## 评论区运营

评论区不是互动区，是需求调研区：

- 回复优先级：① 明确说行业的 ② 明确要模板/框架的 ③ 说有产品但不会获客的 ④ 提出反驳补充的 ⑤ 只表达认同的。
- 置顶一条带关键词的引导评论（增加搜索词密度）。
- 每周复盘一次评论区：高频行业、高频问题、线索信号、可追更选题——出现"能不能按我的行业改"的需求，72 小时内出追更。

## 线索有效性判断

只点赞、只评论"讲得好"不是线索。有效线索＝用户表达了明确需求、预算、场景、时间或具体问题。每周统计：有效咨询数、私域进入率、跟进结果——这三个数比播放量重要。
