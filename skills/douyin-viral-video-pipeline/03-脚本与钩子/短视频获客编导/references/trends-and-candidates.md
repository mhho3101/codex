# 热点与候选池（trends adapter 约定）

> 目的：日常补充选题候选池，不让"今天拍什么"断粮。热点是候选来源之一，不是必蹭。

## 候选池文件

`clients/<id>/01-topics.md` 底部的候选区，每条候选一行：

```text
- [YYYY-MM-DD] 候选句 ｜ 来源：热点/搜索/评论/对标 ｜ 来源链接或出处 ｜ 状态：待评/已评/已用/已弃
```

## 热点源接入约定（adapter）

任何热点源（热榜/行业信源/RSS/搜索结果页）接入时按统一格式产出候选：

| 字段 | 说明 |
| --- | --- |
| 候选句 | 一句话选题方向（不是标题照抄） |
| 来源 | 哪个源 |
| 时效 | 热点有效期判断（24h/本周/长期） |
| 与本客户相关度 | 高/中/低 + 一句理由 |

## 使用规则

1. 候选入池≠进排期：一律过评分闸门（通用 8 项 + 专属权重）；
2. 蹭热点三问：与本客户行业相关吗？目标客户关心吗？48 小时内能拍出吗？三个"是"才进入评分；
3. 过期候选每周清理一次（标"已弃"并留原因），候选池保持"当前可用"。
