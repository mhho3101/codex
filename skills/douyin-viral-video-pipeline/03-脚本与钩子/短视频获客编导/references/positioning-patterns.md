# 定位模式库（模块 A · 策划诊断用）

> 用途：定位五步（planning.md）每一步都有据可依——本卡是定位方法论的**单一正本**（去客户化、行业无关、可公开发行）。
> 证据分级：★=公司内部已验证方法论（60+ 老板 IP 实操沉淀）；☆=公开网络方法论（多源互证，标题级证据标出）。
> 用法：出定位卡前按本卡逐项过；定稿后过 §J 验证清单。

## A. 定位四维（先想清楚四个问题）☆

| 维度 | 问什么 |
| --- | --- |
| 用户需求 | 目标观众正在为什么具体问题发愁？ |
| 平台规则 | 这个赛道的内容在平台上怎么被分发（推荐页/搜索页）？ |
| 竞品差异 | 同行都在怎么讲？我们能不一样在哪？ |
| 自身优势 | 客户独有的身份/经历/资源是什么？ |

## B. 定位公式 ☆

```text
定位 = 人设 + 场景 + 呈现方式 + 主要内容形式 + 记忆点 + 价值
```

六项缺一，定位就模糊。记忆点最易漏：一个让观众记住的固定符号（口头禅/固定开场/视觉符号）。

## C. 人设四要素 + 放大法 ☆

人设 = **身份 + 理念 + 行为 + 特点**。

客户觉得自己"普通、没特点"时用**放大法**：把原本的小特点放大成人设——一点幽默放大成搞笑，一点急躁放大成坦率暴躁，内向放大成"面瘫脸"。普通特点放大即独特。

## D. 差异化两路径 ☆

1. **避开撞车**：同行都枯燥口播，你换呈现形式（动态字幕/实拍/剧情）；
2. **提升密度**：同行讲废话凑时长，你给清晰有序的高密度干货。

差异化的操作元素永远是四个：**产品、呈现方式、文案、个人形象**。
（二次创新五策略——乘法/减法/除法/一专多能/属性依存：标题级证据，需深化时再调研。）

## E. 目标客群拆解法 ★

别凭"我以为"。把客群**拆到具体身份**：如宠物行业拆成门店/品牌代理/活体店/医院/养宠人/博主，再细分到 8 种身份。起号优先做给**爱分享、愿传播**的人看——他们是破圈钥匙。每条视频先想清"拍给谁看、谁会转发"。（90% 的老板死在这一步。）

## F. 起号三目标 ★

定位不是只为流量，要同时拆出三个目标：
1. **行业破圈**：做出业务爆款让全行业看见；
2. **精准获客**：内容兼顾曝光+获客变现；
3. **跑通闭环**：短视频↔直播/私域串起来。

## G. 账号构建规范 ☆

- **昵称两策略**：传播优化（独特易记）或搜索优化（带行业关键词，如"XX的短视频运营"）；
- **简介三点**：我是谁 / 我的领域 / 我能给你什么（≤242 字）；
- **头像**：真人照片优先；背景图高清统一风格。

## H. 高配版定位：场景三传递 ★

拍摄场景不是背景板，要同时传递三样：
1. 你和客户的**关系感**；
2. 你对事的**掌控力**；
3. 你在行业的**专业度**。

## I. 变现路径先定 ☆

- **有产品**：直播售卖 / 私域转化 / 店铺引流，三选一为主；
- **无产品**：流量收益 / 带货 / 广告合作（天花板低，建议尽快产品化）。
变现路径不定，内容方向就会漂移。

## J. 定位验证清单（定位卡定稿前必过）

- [ ] 四维都答出来了（A），不是只写了"我是谁"
- [ ] 公式六项齐全，记忆点明确（B）
- [ ] 人设有特点或经过放大（C）
- [ ] 说清了和同行的一个明确差异（D）
- [ ] 目标客群拆到了具体身份，不是"老板/大众"（E）
- [ ] 起号三目标有取舍排序（F）
- [ ] 昵称/简介符合规范（G）
- [ ] 变现路径已选定（I）
- [ ] 差异化假设可被内容验证（能写成选题）
