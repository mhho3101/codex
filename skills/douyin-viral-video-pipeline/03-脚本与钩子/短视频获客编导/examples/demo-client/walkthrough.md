# 演示：虚构客户「远山机械」从策划到回标全流程

> 本演示客户为**虚构**（小型工业设备厂商，想做抖音获客），仅用于展示工作流每一步的输入输出。

## 模块 A · 策划诊断

```bash
python scripts/director.py onboard demo001 "远山机械" "工业设备" "评论『选型』"
# ✅ 客户 demo001（远山机械）已建在 clients/demo001/：五件套 + matrix.json 词表模板
```

采访后填 `clients/demo001/00-console.md` 关键结论：

```text
商业任务：咨询线索
目标客户：第一次采购设备、怕买错影响产线的小工厂老板
付费时刻：订单来了但现有产能跟不上，必须 1 个月内上设备
转化动作：评论「选型」，发产品规格和使用场景
采访原话：「最怕的不是贵，是买回去配不上产线，退货又拖一个月。」
```

填 `clients/demo001/matrix.json`（词表来自采访原话）：

```json
{
  "core": "设备选型",
  "related": ["产线匹配", "调试周期", "售后响应", "退货风险", "参数怎么看", "二手设备"],
  "personas": ["第一次采购的小厂老板", "刚接订单的代工厂", "预算有限的初创厂", "被售后坑过的采购"]
}
```

## 模块 B · 选题生成

```bash
python scripts/director.py matrix demo001
# ✅ demo001: 24 条组合 -> clients/demo001/matrix-topics.md

python scripts/director.py assemble demo001
# ✅ demo001: 23 条候选 -> clients/demo001/auto-topics.md

python scripts/director.py score
# 选题一句话：第一次采购设备怕配不上产线？先问清这 5 个参数
# 人群清晰：2  痛点具体：2  钩子强度：2（3 筛选清单体） 普通人可懂：2
# 判断标准/产物：2（5 参数清单） 信任证据：1  线索入口：2  合规：2
# → 总分 15/16 → S 级（≥14，重点磨）
```

录入选题库：钩子体＝第 3 类筛选清单体；流量场景＝搜索页（"参数怎么看"是真实搜索词）→ 标题带搜索词：「第一次买设备怎么选？5 个参数先问清（选型避坑第 1 期）」。

## 模块 C · 脚本生产（节选）

```text
钩子（首句给答案，搜索页结构）：
「第一次买设备，别问价格，先问这 5 个参数。」

问题：「最怕的不是贵，是买回去配不上产线——退货再换，一个月产能就没了。」（客户采访原话）
解法：错在哪（先看报价单）→ 为什么（报价单看不出匹配度）→ 怎么做（按 5 参数问）
小切口：给 5 参数清单（材料规格/节拍/占地/电力/售后响应时效）
证据：真实素材来源＝2026-07 客户交付现场记录
结尾转化：「评论『选型』，把清单发你；拿不准的，发我你的产品规格，我帮你看。」
```

四关校验：✅ 钩子关（首句给答案）✅ 格式关 ✅ 结构关 ✅ 逻辑关 → 定稿。

## 模块 D · 发布与承接

- 排期检查：上一条用的是 15 真实复盘体，本条 3 筛选清单体——不冲突 ✅
- 承接话术已写：评论「选型」→ 回复追问行业/产品/客户 → 发清单 → 判断是否能帮
- 预测表现（盲打分）：播放 3k-8k，收藏 > 点赞，评论出现 5+ 条「选型」

## 模块 E · 数据回标（发布后 3 天）

```text
实际数据：播放 5200 ｜ 完播 38% ｜ 点赞 210 ｜ 收藏 340 ｜ 分享 96 ｜ 评论 61 ｜ 线索 9
偏差分析：播放预判准；收藏高于点赞验证了"清单型内容被当工具收藏"；线索 9 条超预期。
复用结论：「5 参数清单」角度有效 → 进拍穿流程，同角度再出 4 条（不同设备类型）。
```

## v3 补充演示：盲预测 → 拍/发分离 → 复盘（可校准循环）

```bash
# 1. 脚本定稿后、发布前：写盲预测（写完不可改）
python scripts/director.py predict demo001 选型避坑清单
# ✅ 盲预测已建档：clients/demo001/predictions/2026-08-21_选型避坑清单.md
# （填 ## 预测 段：钩子体/评分/预测表现/判断依据——必须在看到任何数据之前）

# 再试一次会被拒绝（immutable）：
python scripts/director.py predict demo001 选型避坑清单
# 预测已存在且不可改 → 要修正请新开 _redo.md

# 2. 拍摄与发布分开登记，buffer 自动警戒
python scripts/director.py shoot demo001 选型避坑清单    # buffer=1
python scripts/director.py shoot demo001 二手设备避坑    # buffer=2
python scripts/director.py shoot demo001 报价水多深      # buffer=3（红灯：停止新拍摄，先发布）
python scripts/director.py recommend demo001
# 红灯：不推荐新选题。先发布库存。

# 3. 发布后 3 天：retro 只追加复盘段，绝不动预测段
python scripts/director.py publish demo001 选型避坑清单  # buffer=2
python scripts/director.py retro demo001 选型避坑清单
# ✅ 复盘段已追加（只追加，未动预测段）→ 填实际数据/偏差分析/Aha 判级

# 4. 攒够 5 条回标后：标准卡升级走 bump 协议
python scripts/director.py bump demo001
# ✅ bump 工作表已生成（N 条校准样本）→ 全量重打→排序一致性≥4/5→独立审核→写入 06-standard.md

# 5. 随时看状态
python scripts/director.py state demo001
# [demo001] 状态: 待拍摄发布 ｜ buffer: 2（黄）｜ Aha判级: 未判
#   轨迹: ... 已拍 → 已发 → 复盘 ...

# 6. 回标评论攒多了，聚类出受众画像
python scripts/director.py persona demo001   # → clients/demo001/audience.md 骨架
```

要点：**预测写错了不能改**（新开 `_redo.md`）；**拍了不等于发了**（buffer 红灯会拦你）；**复盘只能往后追加**（改历史等于骗自己）。
