# Feedback Routing

Use this table after each user review. Record the exact feedback in `ITERATION_FEEDBACK.md`, then change only the smallest affected layer.

| User says | Diagnose | Change now | Preserve |
|---|---|---|---|
| “开头没有钩子” | Promise arrives too late or has no landing event | Rewrite/retime 0–3 seconds; add one visual landing and restrained SFX | Later accepted script and scenes |
| “主题没有出现” | Main subject is only implied or too small | Add full subject card in first 12 seconds and at first spoken mention | Core structure and narration unless wording is wrong |
| “词写错了” | Canonical terminology drifted | Update all public text in one pass | Timing if the spoken wording is unchanged |
| “声音太机器人” | Voice identity or delivery is unsuitable | Audition 2–4 voices; replace after user selection | Script; rebuild only timing-dependent layers |
| “参考这个音效” | Sound density/rhythm lacks editorial logic | Map opening, transition, list, warning, and completion events; use library SFX first | Approved voice and visuals |
| “加音效拉住前三秒” | Opener lacks auditory landing | Use a short impact/click, rise, and/or whoosh around actual visual events | Narration intelligibility |
| “封面按这个参考” | Cover hierarchy or style needs correction | Make a new 3:4 cover; lock exact copy and dominant subject | Final video |
| “视频违规了” | Possible claim, disclosure, source, brand, or AI-label risk | Audit title, claims, AIGC declaration, visible label, sources, and brand context | Accepted educational core where defensible |
| “画面太空、素材不足” | Material mapping or storyboard density | Add directly mapped evidence, workflow artifacts, interfaces, recordings, or explanatory graphics | Accepted script and narration |
| “文字互相遮挡” | Layer state or layout | Fix exit, entrance, safe zones, and readable hold time | Script and narration |
| “动画和口播不同步” | Keyword timing anchors | Re-anchor HyperFrames motion and ChatCut SFX; inspect prior, landing, and completion frames | Accepted spoken wording |
| “A 改成 B，其他保留” | Subject-dependent wording and assets | Perform minimal substitution only | Approved structure, general teaching points, rhythm, and unrelated scenes |
| “某个事实错误” | Source or script claim | Reverify and correct the affected claim and dependent public text | Unrelated scenes and accepted facts |

Never treat a request for stronger hook, subject visibility, sound, voice, cover, or compliance as authorization to overwrite a prior accepted export.
