## 二、S 级技能包（16 个，优先使用）

### 1. OpenMontage全能制作 · 61,640★
**定位**：开源 agentic 视频制作系统 —— 12 条产线 + 138 个 skills。
**亮点**：产线覆盖动画解说/角色动画/电影感/切片工厂/纪录片/口播/播客再剪/本地化配音/屏幕演示；
是真正的"视频视频"（检索免费素材库真实运动镜头剪辑），非"把几张图动起来"；曾获 GitHub Trending #1。
**坑**：⚠️ AGPL-3.0；体积大，需 Python 环境。
**建议**：把它当"总装车间"，其他包当零件。

### 2. 电影级镜头配方 · 9,775★
**定位**：157 张镜头配方卡 + 214 个动效预览 + 完整 Remotion 模板（Ink Press）。
**亮点**：每张卡含用途/能量值/建议时长/参数/实现要点/已知坑；附**剪映工程导出**（可继续在剪映改）；
有 headless 渲染踩坑记录（并发上限、chrome-headless-shell、CDN 阻塞）。
**坑**：需 Node + 首次下载 chromium。
**建议**：想做"电影感"必备。用 Ink Press 模板起步最快。

### 3. 多模态生成技能包 · 4,333★
**定位**：73 个 skills，图片/视频/音频/3D 全模态生成。
**建议**：素材生成的百宝箱，按需调用。

### 4. 剪映AI自动化剪辑 · 3,560★
**定位**：自然语言驱动剪映完成 文案→配音→字幕→选音乐→特效→导出。
**亮点**：这条线上**最受欢迎的剪映自动化 skill**，中文原生，对接国内最主流剪辑工具。
**建议**：普通人做抖音的最短路径。

### 5. 短剧漫剧创作全套 · 2,333★
**定位**：AI 短剧/漫剧全流程（剧本→角色资产→分镜→提示词→审查）。
**亮点**：12 skills、275 个 md、含 `evaluations/` 评测集与 `tests/`，工程化程度极高。

### 6. 剪映草稿自动化 · 1,877★
**定位**：生成/下载剪映 draft 文件（含 API 服务 + 扣子插件 + 桌面端）。
**亮点**：能把 AI 生成结果直接落成**可编辑的剪映工程**，是"AI→人工精修"的最佳桥梁。

### 7. 分镜脚本规格生成 · 998★
**定位**：把模糊想法逼成**精确到秒**的 `video-spec.md` 分镜脚本。
**亮点**：解决"AI 生成的脚本太空泛"的通病，是衔接脚本与渲染的关键一环。

### 8. 爆款视频拆解包 · 5★（垂类黑马）
**定位**：把任意爆款视频变成可复盘的创作者研究包。
**亮点**：
- 输出契约清晰：`source.mp4` + `keyframes/` + `speaker_transcript.md` + `story_analysis.md`
- 支持抖音分享链接 / 本地视频 / yt-dlp 全平台链接
- 逐字稿带**说话人区分**（faster-whisper + FunASR/SenseVoice）
- 分析维度硬核：前 3 秒钩子、剧情节拍、反转、镜头节奏、评论区共鸣
- 中间文件收进 `_work/`，最终目录干净
**坑**：需 ffmpeg + Python + yt-dlp + ASR 模型；采集评论需浏览器登录态。
**建议**：**整套包的第一优先级**。做爆款的前提是拆爆款。

### 9. 爆款视频逐镜拆解 · 6★
**定位**：镜头级拉片 + 爆款机制 + **AI 生产蓝图**。
**亮点**：直接输出「可投喂视频生成模型的 brief」，把拆解与生成打通。

### 10. 抖音TopN采集改写 · 4★
**定位**：按点赞量采集 Top N 热门 → 下载 → 语音转文字 → 逐字稿校正 → 文案改写 → Word 交付。
**亮点**：有完整 Python 包、CLI、`doctor` 自检、CI、测试；两个独立 Skill（采集 + 改写）；固化输出契约与 Word 模板。
**坑**：首次需扫码登录。
**建议**：需要**批量对标**时用，比手工逐个拆解快 10 倍。

### 11. 爆款3秒钩子脚本 · 5★ ⚠️无许可证
**定位**：钩子 + 节奏化短视频脚本生成器，专注"前 3 秒"这一决定生死的位置。

### 12. 抖音成片工作流 · 2★
**定位**：给整个视频项目建立工程化档案。
**亮点**：11 套模板 —— PROJECT_BRIEF / SCRIPT / STORYBOARD / MATERIAL_TO_SCRIPT_MAP / SFX_PLAN / COMPLIANCE_CHECKLIST / PUBLISH_PACKAGE / VERIFICATION / ITERATION_FEEDBACK…
**价值**：**把"凭感觉拍视频"变成"按流程交付"**，还带合规检查与发布包。
**建议**：做系列账号必用，保证每条视频质量稳定。

### 13. 封面增长工作流 ⚠️无许可证
**定位**：封面增长优先级决策 + 排版工作流（中文由后期添加，不交给生图模型）。

### 14. 口播解说动作库 · 1,272★
**定位**：口播驱动解说的动效工作室 —— 109 个动效卡 + 逐词配音同步 + 反 PPT 式运镜系统。

### 15. 抖音去水印MCP · 1,273★
**定位**：提取抖音无水印视频链接 + 视频文案（MCP Server，含 ASR 模块）。

### 16. HyperFrames剪辑套件 · 1,064★
**定位**：30 个 skills 的动效工程化制作套件（HyperFrames 体系的学生版全集）。
**亮点**：把动效从"手工拖时间线"变成"写代码描述运动"——逐词字幕、图形说明、
数据动画、转场都有成套 skill；配 `MOTION_PHILOSOPHY.md` 讲清运动设计原则而非只给模板。
**坑**：需 Node + 首次渲染下载 chromium；学习曲线比剪映陡。
**建议**：想做出"不像模板"的高级感，这一套比单纯的动效包更值得投入时间。

## 三、组合推荐（五种打法）

### 打法一 · 个人博主快速起号（零成本）
```
爆款视频拆解包 → 爆款3秒钩子脚本 → 剪映AI自动化剪辑 → 抖音自动发布
```
全免费、中文原生、当天能出片。拆解学结构，剪映出成片。

### 打法二 · AI 内容工厂批量产出
```
抖音TopN采集改写 → 分镜脚本规格生成 → 即梦免费生图生视频
  → 电影级镜头配方 / TikTok短视频动效 → 带货爆款反推 → 抖音自动发布
```
素材全 AI 生成，适合矩阵号与带货。

### 打法三 · 知识 IP 高质量口播
```
爆款视频逐镜拆解 → 短视频获客编导 → AI电影分镜与提示词
  → 口播解说动作库 / 万物皆可讲解 → 封面增长工作流
```
重内容质量与完播率，适合知识付费变现。

### 打法四 · 短剧 / 剧情号
```
爆款短剧编剧引擎 → 短剧漫剧创作全套 → 剪映草稿自动化 → 抖音自动发布
```

### 打法五 · 动效 / 信息流增长（科普·数据·带货）
```
动态字幕排版 → 数据可视化动效 → 讲解动效
  → 电影级镜头配方 / HyperFrames剪辑套件 → 封面增长工作流
```

以信息密度和视觉节奏取胜，适合知识科普、数据解读与信息流带货，完播与前三秒抓取靠动效节奏撑住。

## 四、已知问题与规避

| 问题 | 影响的包 | 规避方式 |
|---|---|---|
| 缺 ffmpeg 直接失败 | 所有视频处理类 | 先 `winget install Gyan.FFmpeg` |
| 抖音采集需登录态 | TopN采集、对标采集、评论采集 | 首次非 headless 扫码登录，遵守平台规则 |
| 依赖第三方付费 API | 多模态生成、即梦(可选)、TikHub | 先用免费路径（剪映/即梦会员）验证 |
| AGPL 传染性 | OpenMontage、本地剪辑台、中文HF导演 | 本地用无碍；做 SaaS 需开源 |
| 无许可证（10 个包） | 见许可清单 | 学习可用，商用前联系作者 |
| 部分包依赖 Playwright | 抖音系采集 | 预留首次安装时间 |
| Remotion 首渲需下载 chromium | 镜头配方、编程视频类 | 网络不通时用本地 chrome-headless-shell |
| 大包体积大 | 本地AI对话式剪辑台(62MB) | 是完整应用源码，按需使用 |

## 五、结论

- **只装 3 个**：`爆款视频拆解包` + `爆款3秒钩子脚本` + `剪映AI自动化剪辑`
- **成体系用**：按 `00-爆款全流程SOP.md` 的 8 个阶段，每阶段取 1–2 个 S 级包
- **要规模化**：加 `抖音TopN采集改写` + `带货爆款反推` + `抖音自动发布`
- **合法合规第一**：拆解是学结构不是搬运；商用务必先查许可证。
