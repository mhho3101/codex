# 快速上手：15 分钟出第一条片

> 目标：**今天就用技能包做出第一条能发的抖音视频。**
> 这条路只走 4 步，不追求完美，只追求跑通。

路径约定：
```
$ROOT = E:\codex\2026-09-28\ban\outputs\技能包精选
```

---

## 第 0 步（5 分钟）· 装两个必装依赖

```powershell
winget install Gyan.FFmpeg
winget install yt-dlp.yt-dlp
```

装完**新开一个终端**，验证：

```powershell
ffmpeg -version
yt-dlp --version
```

> 这两条命令报错，后面一半的技能包都跑不起来。**先解决这个再往下。**

---

## 第 1 步（3 分钟）· 拆一条对标爆款

去抖音找一个同赛道、数据明显好的视频，复制分享链接，然后对 Agent 说：

```text
读取 $ROOT\02-爆款拆解\爆款视频拆解包\SKILL.md，
按它的完整流程拆解这条视频：[粘贴抖音分享链接]
输出目录：E:\codex\2026-09-28\ban\work\拆解\<视频标题>

要求：
1. 严格按 SKILL.md 的 Output Contract 产出 source.mp4、keyframes/、
   speaker_transcript.md、story_analysis.md 四个文件
2. story_analysis.md 必须是具体的创作者研究报告，不要留占位文字
3. 评论区只采约 30 条，保守采集
```

> 第一条会慢（要下 ASR 模型），大约 10–20 分钟。模型缓存好之后，后面每条 2–3 分钟。
> ⏱️ **建议这一步在后台跑，你同时做第 2 步。**

**拿到 `story_analysis.md` 后，只看这 3 个东西**：

1. 前 3 秒说了什么、给了什么画面
2. 一共几个节拍、反转在哪一秒
3. 高赞评论在共鸣什么情绪

这就是你要抄的**结构**。

---

## 第 2 步（5 分钟）· 写钩子和脚本

```text
读取 $ROOT\03-脚本与钩子\爆款3秒钩子脚本\viral-hook-script-skill\SKILL.md
模式：快速生成

我的选题：[你要讲的事]
平台：抖音   时长：30 秒   画幅：9:16
出镜方式：[真人出镜 / 只配音]
目标：[涨粉 / 带货 / 引流]
参考结构：[粘贴第 1 步拆出来的节拍结构]

请输出：10 个钩子 + 最佳钩子 + 30 秒脚本 + 简化分镜 + 标题 + 封面文案。
```

**钩子验收标准**（不满足就让它重出）：

| 检查项 | 标准 |
|---|---|
| 口播时长 | ≤3 秒 |
| 画面字数 | 6–18 个汉字 |
| 刺激点数量 | **只有 1 个** |
| 有没有编造 | **不许编数据、案例、收益** |
| 有没有老套标题党 | 不许「震惊」「看完惊呆」 |

---

## 第 3 步（5 分钟）· 用剪映出片

把素材（自己拍的 / 网上找的 / AI 生成的）放进一个目录，然后：

```text
读取 $ROOT\06-剪辑与合成\剪映AI自动化剪辑\SKILL.md，
按它的流程帮我把这条视频剪出来：
素材目录：[你的素材目录]
文案：[粘贴第 2 步的 30 秒脚本]
风格：[快节奏知识口播 / 慢节奏治愈 / 剧情]

要求：自动配音、自动生成字幕（不能有错别字）、按语义切分镜头、
背景音乐音量压到 -18dB 左右、导出 1080x1920 MP4。
```

**导出前自己过一遍这 5 条**：

- [ ] 前 3 秒有钩子，不是废话铺垫
- [ ] 没有超过 5 秒的静止画面
- [ ] 字幕逐句对齐，无错别字
- [ ] BGM 没盖住人声
- [ ] 关键信息不在底部弹幕区 / 右侧按钮区

## 第 4 步（可选）· 发布

手动发最稳。想自动发：

```text
读取 $ROOT\07-发布与增长\抖音自动发布\SKILL.md，
把这条成片上传到抖音创作者平台：
视频路径：[final.mp4]
标题：[标题]   简介：[简介]   话题：[话题]

上传后停在发布确认页，让我自己点最后一下。
```

> 前置：Chrome 里已经登录抖音；只用 `target="host"`，不要填其他 profile 参数。

---

## 发完之后做什么

记录 **2 小时 / 24 小时 / 72 小时** 的数据：

```text
读取 $ROOT\03-脚本与钩子\爆款3秒钩子脚本\viral-hook-script-skill\SKILL.md，
按「数据复盘」模式分析这组数据：
播放：____   5 秒完播率：____   完播率：____
点赞：____   评论：____   收藏：____   转发：____

请诊断是钩子问题、节奏问题、内容问题还是发布时间问题，
并给出下一版的 5 条可执行修改建议。
```

---

## 记住三句话

1. **前 3 秒定生死**。钩子不行，后面做得再好也没人看到。
2. **爆款是迭代出来的**。前 10 条是为了收集数据，不是为了爆。
3. **先拆后拍**。抄结构不抄画面，抄方法不搬内容。
