# AI Film Team Storyboard 1.8.1

面向中文 AI 影视制作团队的执行型 Codex Skill，覆盖故事板、黑白线稿、资产提示词、视频提示词和明确授权后的剧本逻辑补充。

## 版本状态

`1.8.1` 是本项目的首个公开版本，但不是从零开始的实验版本。它是在此前团队包多轮迭代、规则收敛和执行校验基础上的较稳定公开基线。后续公开更新继续沿用团队版版本线，例如 `1.8.2`、`1.8.3`。

公开发布从 `1.8.1` 开始；更早的内部版本没有随本仓库发布。

## 能做什么

- 根据用户提供并确认的剧本、讲戏表或分镜头表执行故事板和黑白线稿任务
- 生成和审查人物、群像、场景、道具、特效资产提示词
- 生成 Seedance、即梦、可灵等视频提示词的可复制正文
- 管理确认版资产、人物首态母版、场景空间母版和 `V1/V2/V3` 版本关系
- 只有在用户明确授权时，补充动作、视线、道具、声音和因果桥接逻辑

## 执行边界

这个 Skill 执行用户提供的制作资料，不替代用户自行重写剧本、重做完整分镜或擅自进入下游模块。正式故事板、分镜图和视频提示词只能调用已确认的完整资产版本。

项目剧本、客户资料、参考图、账号信息、API 密钥和其他私人素材不属于本仓库，使用时请保存在本地项目目录，不要提交到 GitHub。

## 安装为本地 Skill

将本仓库目录放入项目级或用户级 Skill 目录，并确保目录内直接包含 `SKILL.md`：

```text
<your-repository>/.agents/skills/ai-film-team-storyboard/SKILL.md
```

也可以将仓库内容复制到 Codex 用户 Skill 目录下名为 `ai-film-team-storyboard` 的文件夹中。安装后显式调用：

```text
$ai-film-team-storyboard
```

首次使用时，先提供本轮剧本、讲戏表/分镜头表、已确认资产和明确交付物；不要把客户资料或密钥粘贴到公共 Issue。
