# 场景资产单张五面空间模板

## 固定版式

场景资产固定生成一张 `2.35:1` 电影宽银幕照片。五面空间必须在同一张照片内同时建立，不做拼图、不做多宫格、不拆成五张视图。

本模板用于三种互斥关系：首次场景空间母版、基于空间母版的时段/天气派生状态、基于空间母版的结构状态。首次出现建立唯一空间母版；后续相同空间结构不得重新设计。

- 夜景、黄昏、黎明、正午、暴雨、雪景、浓雾、火灾、停电、烟尘等会显著改变可见状态且需要作为生成参考时，按首次发生场次建立时段/天气派生状态；单纯机位、情绪或临时动作变化不新建。
- 派生状态必须写明 `基于@【原场景空间母版】`，完整继承门窗方位、空间比例、道路方向、固定坐标、建筑身份和基础材质，只修改剧本规定的时段、天气、实景灯、天空、曝光、阴影、湿度或环境状态。
- 永久结构、固定陈设、道路关系或破坏程度变化时建立结构状态，同样基于原空间母版。后续同类状态复用首次派生，不重复生产。

五面空间是：左侧空间边界、右侧空间边界、上方结构或天空/主光来源、地面行动平面、正面背景纵深。室内对应左墙、右墙、天花、地面、背景墙/门窗；外景必须把左右边界具体化为院墙、路沿、树林、山坡、水沟、建筑侧墙、篱笆或田埂，并交代道路与建筑的经过、通向、横穿或尽头关系。

## 可复制完整模板

```text
优先使用 GPT Image 2 / gpt-image-2；输出 4K 或当前平台可选最高分辨率/最高质量。

@【集数-场次场景名】，单张 2.35:1 电影宽银幕横向场景资产照片，真实电影摄影棚实景搭建感，不是拼图、不是多视图、不是多宫格、不是概念图、不是游戏场景或 3D 渲染。画面必须在同一个透视和同一张照片内完整建立五面空间：左侧为【具体左边界】；右侧为【具体右边界】；上方为【天花/屋顶/天空/主光来源】；下方地面为【材质、行动平面和路线】；正面背景纵深为【背景墙/门窗/道路/远景开口和空间终点】。五面之间透视、比例、材质和光影连续，不能把五面拆成五张图。

场景资产关系：【首次场景空间母版 / 基于@【原场景空间母版】的时段或天气派生状态 / 基于@【原场景空间母版】的结构状态】。父资产：【@完整原场景空间母版名；首次母版填无】。固定继承项：【门窗方位、空间比例、道路方向、固定坐标、建筑身份和基础材质】。本次唯一变化及剧本依据：【首次母版初始状态 / 夜景黄昏黎明天气火灾烟尘的可见变化 / 永久结构或破坏变化】。后续相同状态复用关系：【场次范围】。

场景身份与剧情用途：【时代、地点、属于谁、阶层/组织、场景情绪、剧情功能】。空间结构：【门窗、门槛、通道、台阶、人物可站/走/跑/对峙区域、固定道具坐标、进入与离开方向】。道路或动线关系：【经过/通向/横穿/尽头及与门、院、建筑的具体关系】。前景为【空间锚点或遮挡】；中景为【主要表演和调度区域】；后景为【纵深、出口、危险、光源或剧情锚点】。

摄影技术规格：ARRI ALEXA 35 电影摄影机观感，使用 20mm-24mm 直线型电影广角镜头，根据空间尺度选定具体焦段【填写具体焦段】，光圈 T8，ISO 800 基准，三脚架固定机位，摄影机高度约 1.5 米并保持水平；深景深让左右边界、上方结构、地面行动路线和正面纵深全部清楚可读。使用直线透视校正，不使用鱼眼、球形全景、极端畸变或超高机位；横向展开空间但不把边缘拉伸变形。

灯光技术规格：主光来自【场景内可信光源及方向】，色温【具体 K 值】，强度【相对曝光或挡位】，照亮【具体区域】；补光来自【方向】，比主光低【具体挡位】，主补光比【具体比例】；轮廓/空间分离光来自【方向和色温】，只分离【结构或材质】；背景亮度比主要行动区低【具体挡位】或按剧情设定；阴影统一落向【方向】，软硬程度【具体描述】。所有窗、门、灯具、天空、火光或月光的动机来源一致，暗部有层次但不死黑，画面清楚、干净、空气通透。

材质物理层：【逐项写木、石、土、金属、布、纸、玻璃、水面等】具有真实粗糙度、反射层次、纤维/颗粒、微小划痕、氧化、边缘磨亮、受控灰尘和使用痕迹；磨损服务时代与身份，不把画面做脏、做油、做灰。墙地、道具与建筑构件有真实接触阴影和人可使用的尺度。

连续性锚点：【列出后续反打、扩图和视频必须保持不变的门窗位置、墙体材质、道路方向、固定道具坐标、主光方向和阴影方向】。

限制：空场景资产，画面中不得出现人物、路人、演员、身体部位、剪影、人影或人物反射；不得输出拼图、多视图、多宫格、五张照片、概念图、海报、商品图、鱼眼全景、镜像空间、虚幻引擎质感、HDR、塑料反光、过度锐化、过饱和或不可拍摄的空间。
```

## 交付审查

审查时必须先确认该行是首次空间母版、时段/天气派生状态或结构状态；复用场次不得重复输出，派生状态必须包含 `基于@【原场景空间母版】` 和固定继承项。随后确认能在一张图里明确指出左界、右界、上方、地面和正面纵深；检查是否为空场景、2.35:1、单一透视、深景深、可调度、摄影机型号/焦段/光圈/机位齐全，以及主光、补光、色温、光比、阴影和材质读光齐全。任何一项无法从提示词中确定，先返工。
