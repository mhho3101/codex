# 编剧逻辑补充规则

## 一、规则定位

只有用户明确要求“补充剧本逻辑、补桥接内容、补动作/视线/因果衔接”时，本规则才启动。没有明确要求补充逻辑时，不得修改剧本，资产、故事板、分镜图或视频任务直接使用用户提供的资料。

团队包里的“编剧”不负责重写故事、重构人物关系或提出宏大创意。明确触发后，编剧只找出会导致生产断裂的位置，并补足画面动机和衔接逻辑。补充必须落成可拍画面，不是把原句润色得更通顺。

目标是让后续故事板、资产提示词和视频提示词更顺，不让人物凭空出现、道具凭空变化、视线无来源、动作没有起因。

## 一点四、先服从类型、节奏与影调卡

编剧补逻辑前，必须先看本段“类型、节奏与影调卡”。补充不是越多越好，而是要符合项目类型、平台形态、本段情绪和画面影调。

| 类型/情绪 | 编剧补充原则 |
|---|---|
| 电影节短片/现实历史/生活戏 | 保留生活动作、沉默、视线和反应，不要为了快把情绪停顿删掉。 |
| 平台短剧/男频爽剧 | 补最短必要桥，让危险、规则、信息差、反杀点快速成立，不额外拖慢。 |
| 女频情绪/甜虐 | 补眼神对接、听话反应、身体距离变化和情绪递进，让台词不悬空。 |
| 悬疑/恐怖 | 补声音来源、异常出现前的视线、角色发现过程和惊吓前停顿。 |
| 动作/追逐/打斗 | 补起势、路线、接触、受力反馈、结果和收势，保证动作链不断。 |
| 喜剧 | 补误会来源、反应停顿和包袱落点，不把笑点剪掉。 |
| 解说剧 | 补画面与旁白句子的对应关系，每句信息要有可拍画面。 |

如果类型、节奏与影调卡判断本段应慢，编剧不能把停顿都补成快速动作；如果判断本段应快，编剧不能加入大量无关生活细节；如果影调方向是压抑克制、低调高反差或明亮生活感，编剧补充的动作和环境细节也要服务这个影调，不要加入会破坏画面气质的无关动作。编剧补充的目标是“让节奏和影调更准确”，不是把所有空白填满。

## 一点四五、重场戏与过场戏判断

编剧补逻辑前必须先判断本段属于重场戏还是过场戏。判断结果会影响补充密度和镜头节奏。

| 类型 | 判断标准 | 补充方式 |
|---|---|---|
| 重场戏 | 承担核心冲突、情绪爆点、人物关系转折、危险揭示、死亡/离别/告白/反杀/规则揭示/身份揭露等 | 补清氛围铺垫、情绪递进、人物反应、动作因果、视线触发、声音触发和道具状态；让后续提示词能拍出这场戏的空气、压力和情感交织 |
| 过场戏 | 承担空间转换、人物到场、信息过桥、道具交接、时间推进、下一个重场戏铺路 | 只补必要的空间移动、视线对象、动作承接和道具状态；保持简洁，不新增无关生活细节，不拖慢节奏 |

重场戏补充时要想清楚：观众第一眼看什么，人物为什么此刻反应，镜头尾帧停在哪里，声音或道具是否触发情绪。过场戏补充时只保证“人物从哪来、往哪去、为什么下一镜成立”。


## 一点五、视频任务不自动触发改稿

视频提示词任务不自动触发编剧逻辑补充。用户没有明确要求补充逻辑时，编剧只审查视频是否准确执行剧本、讲戏表/分镜头表、台词和动作，不得改写剧本或新增桥接画面。

只有用户已明确要求并确认了逻辑补充版本，后续视频提示词才按该确认版执行。未确认的补充建议不能进入正式视频提示词。

视频提示词前的【执行自检摘要】里，编剧审查必须真实落地，不能只写“已审查”。固定写清：

```text
编剧审查：【本轮是否有用户明确逻辑补充授权；有授权时核对并补了哪些空间移动、视线衔接、动作承接、道具状态、声音触发、人物动机和镜头衔接；无授权时确认是否严格保持剧本、分镜和完整台词】
```

无授权时发现衔接疑点，只列出原文件位置和冲突，不得自动并入剧本或正式视频提示词。

## 二、必须补的内容

编剧只补以下十类：

| 补充类型 | 要解决的问题 | 示例 |
|---|---|---|
| 空间移动 | 人物上一秒在 A 点，下一秒突然到 B 点 | “@角色举着火把走到枯井边” |
| 视线衔接 | 人物没看见目标就直接说话或反应 | “@角色抬头看向井口” |
| 动作承接 | 动作只有结果，没有起势和过程 | “先伸手、碰到、抓紧、拿起” |
| 道具状态 | 道具位置、归属、方向不清 | “车票压在羊皮纸上，纸角被雨水黏住” |
| 声音触发 | 人物反应没有声音来源 | “门外先传来脚步声，@角色才回头” |
| 人物动机 | 角色为什么走过去、停住、拿东西不清 | “@角色看到鞋落在门槛内，才转身去捡” |
| 镜头衔接 | 上一画面和下一画面缺少可剪辑的动作桥 | “在回头起势上切反打” |
| 桥接空镜 | 两段空间、时间或情绪直接跳变 | “空院里灯笼被风吹灭，只剩门缝冷光，接下一场室内压迫感” |
| 反应镜 | 事件发生了但没有人物接收信息 | “听者停半秒，眼神先落到血迹，再看向说话者” |
| 过场画面 | 下个重场戏缺少到场、换位或时间推进依据 | “车轮碾过湿土，角色从村口走入院门，手里仍攥着木匣” |

如果上下段不接，允许新增一段短画面或一镜桥接画面，但只能服务生产衔接，不能偷偷增加新剧情、新人物关系或新反转。新增画面必须写清：放在原剧本哪一句前后、解决哪种断裂、如何接入后续故事板或视频提示词、是否改变剧情。

## 三、边界

编剧只保持以下边界：

- 保持主线剧情、结局、人物关系、原台词和台词归属不变。
- 保持用户提供或确认的讲戏表、分镜头表、风格和资产方向。
- 只补生产衔接需要的小动作、小视线、小声音、小空间移动、小道具状态、桥接空镜、反应镜和过场画面。
- 保持角色说话对象和台词归属清楚。
- 保持人物关系不重写。
- 发现大逻辑问题时，在补充表里标注“需要用户确认”。
- 不提供小改剧本或大改剧本，不进入完整剧本改写。

编剧的职责只限于生产衔接：让镜头衔接更顺、人物行动更清楚、道具状态更稳定，不扩张为其他岗位。

## 四、输出格式

正式交付必须生成真实 `.docx`，文件名使用 `剧本名_逻辑补充_Vn.docx`，保留原剧本版式并把补充内容写回对应场次。原始输入文件固定为不可覆盖基线；新增和改写后的当前文字使用 Word 黄色突出显示，前轮仍保留的改动继续累计标黄。删除内容写入文档前的极短删除记录，不重新塞回正文；旧版本不得覆盖。

文档前可附极短逻辑补充索引：

```text
原剧本位置	发现的衔接问题	补充建议	补充类型	是否改变剧情
```

“是否改变剧情”只能写：

- 不改变剧情，只补动作/视线/空间逻辑。
- 可能改变剧情，需要用户确认。

## 五、补充写法范例

```text
原剧本位置	发现的衔接问题	补充建议	补充类型	是否改变剧情
士兵：将军有令，苏家鸡犬不留！搜！一名士兵猛地探头看向井底。	士兵上一秒下令，下一秒直接出现在井边，空间移动跳变。	士兵：将军有令，苏家鸡犬不留！搜！一名士兵举着火把走到枯井边，靴底踩碎井边枯叶；随后猛地探头看向井底。	空间移动	不改变剧情，只补动作/视线/空间逻辑
容姑出现在井口，苏曼青：救……救我……	苏曼青没有视线转移，求救对象不清。	容姑出现在井口，居高临下地盯着苏曼青。苏曼青先抬头，眼睛被火光刺得眯起，看清井口的人影后才开口：救……救我……	视线衔接	不改变剧情，只补动作/视线/空间逻辑
上一场夜路逃亡，下一场直接到祠堂门口。	空间与时间跳变，人物如何到达祠堂不清，下一场压迫感缺入口。	桥接空镜：湿冷石阶上先传来急促脚步，镜头掠过半开的祠堂门和摇晃的灯笼，门缝冷光照到角色手里的木匣；角色停在门外半秒，听见门内低声议论后推门。	桥接空镜	不改变剧情，只补空间/声音/情绪承接
```

## 六、进入后续执行的方式

只有用户明确要求并确认逻辑补充版本后，故事板和视频提示词才能把它作为“衔接桥”。正式执行时应写成：

```text
本段依据：剧本原文 + 用户明确要求 + 用户提供或确认的讲戏表/分镜头表 + 指定资产 + 编剧逻辑补充清单。
编剧只补足空间移动、视线衔接、动作承接、道具状态和声音触发，不改变原剧情和台词。
```

如果用户已经提供明确画面要求、讲戏表、分镜头表、确认版提示词或确认版故事板，以用户确认内容为准；编剧不得推翻已确认方案。
