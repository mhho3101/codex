# Security Policy

## 不要公开提交的内容

请不要在 Issue、Pull Request 或公开提交中放入：

- API 密钥、账号密码、访问令牌或本地配置
- 客户资料、未公开剧本、项目素材和内部参考图
- 未获授权的书籍原文、课程资料或商业模板
- 含个人身份信息的生产文件

## 报告方式

普通规则错误和可复现的 Skill 问题可以提交公开 Issue。涉及凭据、个人信息、客户资料或私有项目的问题，不要公开粘贴原文；请先删除敏感内容，再通过仓库维护者主页提供的私下联系方式报告。

本仓库不承诺第三方模型、平台入口或外部连接的安全性和持续可用性。使用前请检查当前平台权限与数据处理规则。
