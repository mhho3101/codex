# 视频制作工作流（Video Production）

用于任何视频创作任务：从想法到成片。按阶段推进，每个阶段完成后再进入下一阶段。

## 阶段 0：需求梳理（必做）

动工前先确认：
- 视频用途：短视频平台（抖音/快手/B站/YouTube）、课程、宣传片、演示录制
- 画幅与时长：横屏 16:9 / 竖屏 9:16 / 方形 1:1；目标时长
- 风格基调：快节奏、知识型、氛围型、产品演示
- 交付格式：MP4/MOV/GIF；分辨率（1080p/4K）
- 是否需要字幕、配音、BGM、特效

## 阶段 1：脚本与分镜

- 写出逐段脚本（旁白 + 画面 + 字幕三栏表）
- 知识/教学类：先定"核心信息点"，每点配一个画面或图示
- 估算每段时长，汇总是否匹配目标时长

## 阶段 2：素材准备

- 录屏：OBS / Xbox Game Bar（Win+G）/ ffmpeg 录屏
- 拍摄素材按场景分目录整理，命名 `01_intro.mp4` 式
- 图片/图表素材：可配合 `data-visualization` 技能生成
- AIGC 素材（图片/配音）按需生成，注明来源

## 阶段 3：剪辑（优先 ffmpeg）

剪辑任务优先用 ffmpeg 命令行（见 `ffmpeg-video-processing` 技能），包括：
- 裁剪/拼接/转场（concat demuxer / xfade）
- 变速、裁剪画面（crop）、缩放
- 多轨混音（BGM 压低、人声保留）

## 阶段 4：音频处理

- 响度归一化到 -14 LUFS（短视频平台标准）
- BGM 淡入淡出，音量压到人声 -18dB 左右
- 人声增强/降噪（afftdn 滤镜等）

## 阶段 5：字幕

- 生成 SRT：先出脚本文本，按时间轴拆分
- 烧录字幕用 ffmpeg `subtitles` 滤镜（中文字体：微软雅黑 `msyh.ttc`）
- 检查字幕断句（每行 ≤ 20 字左右）与错别字

## 阶段 6：导出

- 平台标准：H.264 + AAC，`-crf 20~23`，`-preset medium`
- 竖屏：`-vf scale=1080:1920`；B站/YouTube：1080p 横屏
- 导出后校验：时长、分辨率、音画同步、文件大小

## 质量检查清单（交付前）

- [ ] 需求阶段确认的所有项目已满足
- [ ] 音画同步，无爆音/无声段
- [ ] 字幕无错别字、不超行
- [ ] 码率/分辨率符合目标平台
- [ ] 文件命名规范，成品与素材分目录存放

## 工作目录约定

- `raw/` 原始素材，`audio/` 音频，`sub/` 字幕，`out/` 成品
- 中间产物命名带版本号（`v1.mp4`、`v2.mp4`），避免覆盖
